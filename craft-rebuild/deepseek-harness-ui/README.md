# DeepSeek Harness 桌面端 UI 复刻

用 Craft Anything v0.6.1 复刻 DeepSeek Harness 桌面端界面（WEB UI 部分）。

## 来源与合规

- 目标：`http://127.0.0.1:3080/`（本机运行的 `@deepseek-ai/dsh` 0.2.2-rc.1 Web UI，即桌面端 Electron 外壳负载的同一界面）
- 模式：**Clean room**（净室）——只读访客可见内容：截图、可见文字、测量出的布局/配色/字号/间距。
  未读取目标 HTML 源码、CSS 规则、脚本、请求。
- 目标软件为 MIT 开源的 DeepSeek Harness，仅用于界面研究。
  原版 Logo、文案、图片未照搬；徽标为示意图形。

## 目录

| 路径                 | 说明                                                                                 |
| -------------------- | ------------------------------------------------------------------------------------ |
| `src/`               | React + TypeScript 源码（10 个文件，约 1315 行）                                     |
| `dist/`              | 生产构建产物                                                                         |
| `capture/`           | Craft Anything 的 Study 产物：3 档宽度截图、`capture.json`（设计令牌）、菜单状态截图 |
| `reference-1440.png` | 原版 1440×900 截图                                                                   |
| `rebuild-1440.png`   | 复刻版 1440×900 截图                                                                 |
| `project.json`       | Craft Anything 项目记录（请求、目标、状态、技术栈）                                  |

## 运行

```bash
npm install
npm run dev      # 开发
npm run build    # 构建
npm run preview  # 预览产物
```

## 还原度

像素级比对（1440×900，逐像素取 RGB 最大通道差）：

| 容差阈值 | 相似度 |
| -------- | ------ |
| >16      | 93.99% |
| >24      | 94.47% |
| >32      | 94.67% |
| >48      | 94.97% |

Craft Anything 自带 Check 阶段（布局 + SSIM 感知）在本轮记录的结论为 **78%，14/14 项声明达标**；
上表是我用同一组截图做的独立像素比对，两种口径都会列出，不取高值冒充结论。

### 已知差异

1. **Logo 形态**：原版为实心鲸形标志；复刻为结构近似的示意图形，非逐点还原。
2. **文案细节**：弹窗正文按 `capture.json` 的可见文本写入，个别标点/换行与原版存在差异。
3. **交互状态**：菜单/弹窗的展开态按抓取到的 4 个状态还原，未覆盖原版全部状态。
4. **深色主题**：按设计令牌的暗色值实现，未逐页与原版暗色截图比对。
