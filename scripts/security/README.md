# 安全体系（scripts/security）

一套在本机与仓库内自持运行的安全能力：**采集 → 判据 → 阻断 → 归因 → 取证 → 上报 → 自愈**。
不依赖任何容器运行时（本仓明令禁用 Docker）。

## 一条命令看全貌

```powershell
node scripts/security/security-audit.mjs          # 十六面总审计（配置面 12 + 对抗面 4）
node scripts/security/security-audit.mjs --json   # 机器可读
```

## 边界（写死，不要越）

- **只做阻断、取证、上报**。不对攻击源发起反向攻击或侵入（违法，且会把受害方变成加害方）。
- **归因止于 ASN / 云厂商**。把 IP 指认到自然人只能走云厂商滥用举报或公安协查，报告里不得出现猜测性指认。
- **不动生产**。防火墙改动必须可回滚（改前备份原规则到 `.ihui-agent/state/`）。**8801 必须不限来源放行**：`aizhs.top`/`www.aizhs.top` 经腾讯 EdgeOne 回源，出口 IP 不固定、无段可白名单；2026-11-24 16:4x 曾收窄为仅回环+内网，EdgeOne 回源立即 522、登录页挂掉，17:0x 回滚。拦截面 = WAF(enforce) + edge guard(enforce) + rate-limit 三道。降级手段是 `IHUI_WAF_MODE=observe`（改 nssm 环境变量后重启，只记不拦），排查误报时用，不要用 `off`。
- **对外文案四条红线**（`block-notice.mjs` + `notice-ledger.mjs` 单测钉住）：① 不冒充国家机关——可写「按国安级对抗标准建设」（本项目自定等级），**不得**写「我们是国家安全机关/国安局认证」，英文同样禁 `national security agency / FBI / CIA`；② 文案说"已取证"就必须真有记录（`ref` 落 `block-notice.jsonl` 并 10 分钟内入链），否则是空口威慑；③ 不写规则 id/阈值/端口/内部路径——那是把绕过说明送给对手；④ 说"第 N 次"就必须真数过（ledger 从日志尾部重建），否则重启后对老对手说"这是你第 1 次"——**一句假话就废掉整篇文案**。
- **本仓不引入任何容器运行时**。容器相关只做静态判据。

## 计划任务

| 任务                           | 频率           | 身份                                                  |
| ------------------------------ | -------------- | ----------------------------------------------------- |
| `IHUI-Attack-AutoBan`          | 每 10 分钟     | SYSTEM                                                |
| `IHUI-Attack-Attribution`      | 每日 04:10     | SYSTEM · **同时串行带动主机三查 + 态势 + 证据链追加** |
| `IHUI-Attack-Attribution-Boot` | 开机后 15 分钟 | SYSTEM                                                |
| `IHUI-Security-Audit`          | 每日 03:30     | SYSTEM                                                |
| `IHUI-Security-Audit-Boot`     | 开机后 10 分钟 | SYSTEM                                                |
| `IHUI-Security-Repair`         | 每 6 小时      | SYSTEM                                                |

> **为什么不给主机三查/态势单独建计划任务（2026-11-24 实测）**：新建的 SYSTEM 任务执行新脚本会永久停在"运行中"（6 分钟不退出，且看不到 node 进程），而同机既有 4 个 SYSTEM 任务全部 `Last Result=0` —— 差异只在"脚本是否已被 HIPS 学习过"，无界面会话里没人点"允许"。改为由已信任的 `IHUI-Attack-Attribution` 串行派发下游，子进程继承已信任的父子链；每次派发的 rc/耗时/末尾输出写 `.ihui-agent/state/downstream-dispatch.jsonl`。实测下游 869ms / 259ms，任务 `Last Result=0`。
