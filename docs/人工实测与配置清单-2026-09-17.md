## 六、微信小程序 AppSecret 获取指南(3-3 登录键,需管理员本人扫码)

> 勘误:平台微信登录走**小程序体系**(WX_MINI_APPID/WX_MINI_SECRET),不是开放平台网站应用。
> AppID 已确认:`wx27028e276ffdbc5d`(miniapp-taro/project.config.json)。

1. 浏览器打开 **https://mp.weixin.qq.com**,用本小程序绑定的管理员微信扫码登录。
2. 左侧菜单「管理」→「开发管理」→「开发设置」页。
3. 「AppSecret(小程序密钥)」→ 点「生成」或「重置」→ 管理员微信扫码验证 → 复制 AppSecret。
   ⚠️ **重置会使旧 Secret 立即失效**:若该小程序已在生产被其他服务使用同一 Secret,先确认使用方再重置。
4. 把 AppSecret 交给 AI(或存入密钥库 F:/BaiduSyncdisk/密钥/微信/ 并告知),由 AI 写入
   `apps/api/.env` 的 `WX_MINI_APPID=wx27028e276ffdbc5d` + `WX_MINI_SECRET=<secret>` 并重启验证。
5. 验证:小程序端发起微信登录 → api 日志无 WX 配置告警 → 登录成功落库。

> 现状说明:本地与生产 api 均未配置 WX_MINI(当前微信登录处于 mock/未启用态),配置后即激活。
