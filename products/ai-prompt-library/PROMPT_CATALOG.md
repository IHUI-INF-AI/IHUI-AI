## 使用方法

1. **选择分类**: 根据需求选择对应分类的 JSON 文件
2. **选择 prompt**: 在文件中查找合适的 prompt
3. **替换变量**: 将 `{variable_name}` 替换为实际值
4. **复制使用**: 复制 prompt_template 到 AI 工具
5. **获得输出**: AI 根据模板生成专业内容
