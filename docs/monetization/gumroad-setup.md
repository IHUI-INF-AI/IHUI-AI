# Gumroad 数字产品上架指南

> **目标**:30 分钟内在 Gumroad 上架 IHUI-AI 的数字产品（AI Prompt Library），开始销售。
>
> **难度**:⭐⭐ 易（个人可注册）
>
> **前置依赖**:已注册 PayPal 或 银行账户

---

## 一、前置条件

- [ ] 用户的邮箱
- [ ] PayPal 账号 / 海外银行账户（用于收款）
- [ ] 数字产品文件（如 `products/ai-prompt-library/ai-prompt-library.zip`）
- [ ] 产品介绍图片（建议 1280×720 px）
- [ ] 产品描述文字（可用项目 `PROMPT_CATALOG.md` 内容）

---

## 二、Gumroad 是什么？

**Gumroad** 是一个面向创作者的数字产品销售平台，让任何人都能销售电子书 / 课程 / 软件 / 模板。

**优势**:
- ✅ 个人可注册，无需企业资质
- ✅ 30 分钟即可上架产品
- ✅ 自动处理支付 / 下载 / 发票
- ✅ 支持信用卡 / PayPal / Apple Pay

**劣势**:
- ❌ 手续费较高:10% + $0.30 / 笔
- ❌ 每周五结算（不是即时）

## 三、注册步骤

### 步骤 1:访问 Gumroad 官网

1. 打开浏览器
2. 地址栏输入:[https://gumroad.com](https://gumroad.com)
3. 按 Enter

![访问 Gumroad 官网](screenshot-placeholder)

### 步骤 2:点击 Sign Up

1. 在 Gumroad 首页右上角，找到 **"Sign up"**（注册）按钮
2. 点击它

### 步骤 3:选择注册方式

页面显示几种方式:
- **Continue with Google**（推荐）
- **Continue with Apple**
- **Continue with Facebook**
- **Continue with email**（邮箱注册）

**推荐**:点击 **"Continue with Google"**，用用户的 Gmail 注册。

![选择注册方式](screenshot-placeholder)

### 步骤 4:设置账号信息

1. **Display name**（显示名）:`IHUI-AI`
2. **Profile URL**（个人主页）:`ihuiai`
   - 主页链接会变成:`https://ihuiai.gumroad.com`
3. **Bio**（简介）:
   ```
   Open-source AI platform. We create premium AI prompt libraries, courses, and tools.
   ```
4. 点击 **"Create account"**

### 步骤 5:验证邮箱

1. Gumroad 会向邮箱发验证邮件
2. 打开邮箱，找 Gumroad 邮件
3. 点击 **"Verify email"** 链接

---

## 四、设置收款方式

### 步骤 1:进入支付设置

1. 登录 Gumroad
2. 右上角点击头像 → **"Settings"**（设置）
3. 左侧菜单 → **"Payments"**（支付）
4. 找到 **"Payout account"**（收款账户）

### 步骤 2:绑定 PayPal（推荐）

1. 点击 **"Connect PayPal"**（绑定 PayPal）
2. 跳转到 PayPal 授权页面
3. 输入用户 PayPal 账号（邮箱和密码）
4. 点击 **"Agree and Connect"**
5. 返回 Gumroad，显示 PayPal 已绑定

![绑定 PayPal](screenshot-placeholder)

### 步骤 3:（可选）绑定银行账户

如果不用 PayPal，也可直接绑定银行账户:
1. 点击 **"Connect bank account"**
2. 选择国家
3. 填写银行信息（Routing Number / Account Number）
4. 验证两笔小额存款（1-2 工作日）

## 五、创建并上架产品

### 步骤 1:进入 Dashboard

1. 登录 Gumroad
2. 点击 **"Dashboard"**（仪表盘）
3. 点击 **"Products"**（产品）标签

### 步骤 2:新建产品

1. 点击右上角 **"New product"**（新建产品）按钮
2. 选择产品类型:**Digital**（数字产品）
3. 选择**Single product**（单一产品，非订阅）

![新建产品](screenshot-placeholder)

### 步骤 3:填写产品基本信息

1. **Name**（产品名）:`IHUI-AI Prompt Library - 200+ Premium AI Prompts`
2. **Description**（描述，支持 Markdown）:
   ```markdown
   # IHUI-AI Prompt Library
   
   200+ carefully crafted AI prompts for developers, content creators, and businesses.
   
   ## What's included:
   
   - 🤖 50+ Coding prompts (TypeScript, Python, Rust, Go)
   - ✍️ 30+ Content writing prompts (blog, marketing, technical docs)
   - 🎨 40+ Creative writing prompts (storytelling, scripts, dialogues)
   - 💼 30+ Business prompts (email, proposals, reports)
   - 📊 20+ Data analysis prompts (SQL, charts, insights)
   - 🌐 30+ Language prompts (translation, localization)
   
   ## Features:
   
   - ✅ Tested with GPT-4, Claude 3, Gemini 1.5, Llama 3
   - ✅ Compatible with all major LLMs
   - ✅ Organized by category and use case
   - ✅ Markdown format, easy to copy
   - ✅ Lifetime updates
   
   ## Sample prompt:
   
   > "You are a senior software architect. Review this codebase structure and suggest 3 improvements for scalability..."
   
   ## License:
   
   Personal use only. Resale / redistribution prohibited.
   
   ---
   
   Visit [https://ihui.ai](https://ihui.ai) for more products.
   ```
3. **Preview text**（预览文字）:`200+ AI prompts for developers and creators`

![填写产品信息](screenshot-placeholder)

### 步骤 4:上传产品文件

1. 在 **"Content"** 区域，点击 **"Upload file"**
2. 选择 `products/ai-prompt-library/ai-prompt-library.zip`（或打包好的文件）
3. 等待上传完成（文件大需几分钟）

### 步骤 5:设置价格

1. 在 **"Pricing"** 区域
2. 选择 **"Paid"**（付费）
3. 输入价格:**15**（美元）
4. 勾选 **"Let customers pay what they want above $5"**（允许客户加价）
5. 最低价设为:**5**（美元）

> 💡 价格建议:`$15`（约 ¥99），允许加价让铁粉多付

![设置价格](screenshot-placeholder)

### 步骤 6:上传封面图

1. 在 **"Cover image"** 区域
2. 点击 **"Upload"**
3. 选择封面图（建议 1280×720 px，PNG/JPG）
4. 等待上传

### 步骤 7:设置分类和标签

1. **Category**（分类）:**Software** 或 **Design & Tech**
2. **Tags**（标签，逗号分隔）:`ai, prompts, gpt, claude, gemini, llm, ai-prompts, prompt-engineering, developer-tools, content-creation`
3. **Rating**（评级）:**Everyone**

### 步骤 8:（可选）设置预览内容

1. 在 **"Preview"** 区域
2. 上传 5-10 个示例 prompt（PDF 或 Markdown）
3. 让潜在客户看到产品质量

### 步骤 9:设置许可证

1. 在 **"License"** 区域
2. 选择 **"Standard License"**（标准许可）
3. 条款:
   - Personal use only
   - Resale / redistribution prohibited
   - Lifetime updates included

### 步骤 10:发布产品

1. 检查所有信息无误
2. 点击右上角 **"Publish"**（发布）按钮
3. 弹窗确认，点击 **"Publish"**
4. 页面显示"Product is live"

![发布产品](screenshot-placeholder)

### 步骤 11:获取产品链接

1. 在产品详情页，找到 **"Public URL"**
2. 链接格式:`https://ihuiai.gumroad.com/l/ai-prompt-library`
3. 复制保存

## 七、手续费与结算

### 7.1 手续费

| 项 | 费用 |
|----|------|
| Gumroad 平台费 | **10%** |
| 信用卡处理费 | $0.30 / 笔 |
| **示例**:$15 销售 | Gumroad 收 $1.80（10%）+$0.30 = $2.10，到手 $12.90 |

### 7.2 结算周期

- **每周五**结算上周销售额
- 通过 PayPal 到账:1-2 工作日
- 通过银行账户到账:3-5 工作日

### 7.3 提现规则

- 最低提现金额:$10
- 自动提现:开启后每周五自动打款
- 手动提现:Dashboard → **Payments** → **"Pay me"**

## 九、常见问题

### Q1:Gumroad 在中国大陆能用吗？

A:可以注册，但收款需 PayPal 或海外银行账户。建议用 PayPal 收款（最简单）。

### Q2:Gumroad 会代扣税吗？

A:**美国客户**:Gumroad 自动代扣销售税（按州税率）
**非美国客户**:不代扣税，但需自行申报

### Q3:可以卖多少种产品？

A:**不限**。一个 Gumroad 账号可以卖无限种数字产品。

### Q4:退款政策是什么？

A:Gumroad 默认提供 **30 天退款保证**。可在产品设置中改为"不退款"。

### Q5:Gumroad 与 Stripe / Lemon Squeezy 有什么区别？

A:
| 对比项 | Gumroad | Lemon Squeezy | 自建 Stripe |
|--------|---------|---------------|--------------|
| 平台费 | 10% + $0.30 | 5% + $0.50 | 2.9% + $0.30 |
| 上架速度 | 30 分钟 | 1 小时 | 1-2 天 |
| 网站流量 | ✅（Gumroad 自带流量） | ❌ | ❌ |
| 控制 | 低 | 中 | 高 |
| 适合 | 新手 | 进阶 | 大型 |

### Q6:能否设置会员订阅？

A:**可以**。Gumroad 支持 Membership 功能（月费订阅），需 Gumroad Premium（$10/月）。
