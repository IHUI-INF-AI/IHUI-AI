## 1. 为什么赞助 IHUI AI

IHUI AI 是 Apache 2.0 开源的全栈 AI 操作系统,核心代码永久免费。赞助是项目持续开发、社区运营与基础设施维护的重要收入来源,确保:

- **保持开源**:核心代码不闭源、不加功能锁。
- **加速迭代**:团队全职投入,更快发布新功能与模型适配。
- **运营社区**:维持 Discord/微信群、Issue 响应、文档维护。
- **独立自主**:不依赖单一投资,保持产品中立性。

## 3. 赞助流程

1. **选择档位**:访问 `/sponsor` 页面,选择适合的赞助等级。
2. **选择付款方式**:GitHub Sponsors / Ko-fi / Open Collective / 对公转账。
3. **完成支付**:按平台指引完成订阅或一次性付款。
4. **权益激活**:支付成功后 24h 内,客服联系确认 GitHub / 邮箱账号,激活权益。
5. **展示上线**:README 致谢 / Logo 在 1 个工作日内更新上线。

## 5. 赞助者权益详细说明

### 5.1 README 致谢

- Bronze 及以上:用户名 + 头像显示在 README "Sponsors" 区域。
- Gold 及以上:Logo(≤200×60px)显示在 README 赞助商区域。
- Platinum 及以上:Logo 显示在官网首页赞助商区域。
- Diamond:战略合作伙伴标识 + Logo 显示在 README 顶部与官网首页。

### 5.2 会员群

- Discord 会员频道 + 微信会员群(择一加入)。
- 与核心开发者直接交流,优先回答问题。
- 群内每周分享开发动态与使用技巧。

### 5.3 技术分享会

- Gold 及以上:季度线上分享会(1 小时),核心维护者主讲。
- 议题:新功能解读、最佳实践、架构深度剖析。
- 录像可回看,会员专属。

### 5.4 1 对 1 咨询(Platinum 及以上)

- 每月 1 小时视频会议,可预约(提前 3 天)。
- 议题不限:架构咨询、技术选型、代码 review、故障排查。
- 未使用时长当月作废,不累积。

### 5.5 定制 Agent 开发(Diamond)

- 每月 5 工时定制开发额度。
- 工时可累积(最多累积 3 个月 = 15 工时)。
- 需求确认后 5-10 个工作日交付。

## 6. 取消政策

- **随时取消**:可在赞助平台(GitHub Sponsors / Ko-fi / Open Collective)随时取消订阅,下月起不再扣费。
- **权益保留**:当月已支付的权益保留至月底,次月停止。
- **已享受权益不退**:已享受的会员群、咨询、分享会等权益不退款。
- **定制开发额度**:取消后未使用的累积工时保留 3 个月,过期作废。
- **对公转账**:已支付周期不退款,可联系客服安排后续不再续费。

## 7. 现有赞助者展示规则

### 7.1 展示位置

| 档位 | README | 官网首页 | `/sponsor` 页面 |
| --- | --- | --- | --- |
| Bronze | 用户名 + 头像 | — | 用户名 |
| Silver | 用户名 + 头像 | — | 用户名 |
| Gold | Logo | — | Logo + 名称 |
| Platinum | Logo | Logo | Logo + 名称 + 链接 |
| Diamond | Logo(顶部) | Logo(显眼) | Logo + 名称 + 简介 + 链接 |

### 7.2 展示规则

- 赞助者可选用 **GitHub 用户名**、**真实姓名**或**企业名称**展示。
- 头像默认使用 GitHub 头像,可替换为企业 Logo。
- 赞助者可随时申请修改展示信息(联系 sponsor@ihui.ai)。
- 取消赞助后,展示信息保留 1 个月,之后移除(Diamond 战略合作伙伴标识立即移除)。
- 匿名赞助者显示为 "Anonymous Sponsor",不展示头像。

### 7.3 Logo 要求

- 尺寸:≤200×60px(Gold)/ ≤300×80px(Platinum/Diamond)。
- 格式:SVG 优先,PNG 次选,透明背景。
- 内容:须为赞助者自有品牌 Logo,禁止违规或侵权内容。
- 审核权归 IHUI AI 团队所有。
