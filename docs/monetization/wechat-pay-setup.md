# 微信支付商户号注册指南

> **目标**:注册微信支付商户号，让 IHUI-AI 项目能接受微信扫码支付。
>
> **难度**:⭐⭐⭐⭐ 难（**需企业资质或个体工商户执照**）
>
> **审核周期**:3-5 工作日

---

## 一、前置条件

- [ ] **营业执照**（企业或个体工商户）
- [ ] 法人身份证（正反面照片）
- [ ] **对公账户**（企业）或 法人个人银行卡（个体工商户）
- [ ] 已注册的微信服务号 / 小程序 / 移动应用
- [ ] 联系人手机号
- [ ] 联系人邮箱

> ⚠️ **重要**:微信支付商户号**必须有企业资质或个体工商户执照**。个人无法直接申请。如果用户没有，请先看 [第 9 节:替代方案](#九替代方案个体工商户注册)

---

## 二、微信支付商户号是什么？

**微信支付商户号**（mch_id）让网站 / App / 小程序能接受微信扫码支付、JSAPI 支付、Native 支付等。

**优势**:
- ✅ 国内用户最常用的支付方式
- ✅ 即时到账（T+1 结算）
- ✅ 手续费低（0.6% / 笔）
- ✅ 支持扫码 / 公众号 / 小程序 / App 全场景

**劣势**:
- ❌ **必须企业资质或个体工商户**
- ❌ 审核 3-5 工作日
- ❌ 个体工商户也需对公账户或法人银行卡

---

## 三、注册步骤

### 步骤 1:访问微信支付商户平台

1. 打开浏览器
2. 地址栏输入:[https://pay.weixin.qq.com](https://pay.weixin.qq.com)
3. 按 Enter

![访问微信支付商户平台](screenshot-placeholder)

### 步骤 2:点击商户接入

1. 在首页右上角，找到 **"商户接入"** 按钮
2. 点击它

### 步骤 3:选择接入场景

1. 页面会显示几种接入场景:
   - **公众号支付** — 微信服务号内支付
   - **小程序支付** — 微信小程序内支付
   - **Native 支付** — 网站生成二维码（**推荐，适合 IHUI-AI**）
   - **APP 支付** — App 内支付
   - **H5 支付** — 手机浏览器内支付
2. 选择 **Native 支付**（让网站显示二维码）
3. 点击 **"立即接入"**

![选择接入场景](screenshot-placeholder)

### 步骤 4:填写商户基本信息

1. **商户简称**:`IHUI-AI`
2. **经营类目**:
   - 一级:**信息技术服务**
   - 二级:**软件开发**
   - 三级:**应用软件服务**（或与项目相关）
3. **客服电话**:+86 用户手机号
4. **商户简介**:
   ```
   IHUI-AI 是开源全栈 AI 平台，提供 AI 工具、提示词库和开发服务。
   ```
5. 点击 **"下一步"**

### 步骤 5:填写主体信息

#### 5.1 主体类型

选择:
- **企业** — 已注册公司
- **个体工商户** — 个体工商户执照
- **政府/事业单位** — 不适用
- **社会组织** — 不适用

#### 5.2 营业执照信息

1. **营业执照照片**:上传清晰的营业执照照片
2. **注册号 / 统一社会信用代码**:从营业执照抄
3. **商户名称**:与营业执照一致
4. **注册地址**:与营业执照一致
5. **营业期限**:与营业执照一致
6. 点击 **"下一步"**

#### 5.3 法人身份证信息

1. **法人姓名**:与营业执照一致
2. **身份证号**:法人身份证号
3. **身份证有效期**:开始日期 - 结束日期
4. **身份证正面照片**:上传
5. **身份证反面照片**:上传
6. 点击 **"下一步"**

### 步骤 6:填写结算信息

1. **结算账户类型**:
   - **对公账户**（企业必填）
   - **法人个人银行卡**（个体工商户可选）
2. **开户银行**:选择银行（工行 / 建行 / 招行等）
3. **开户银行省市**:选择
4. **开户名称**:与营业执照一致
5. **银行账号**:对公账号 / 法人银行卡号
6. **预留手机号**:银行预留手机号
7. 点击 **"下一步"**

> 💡 **结算周期**:T+1（次日到账）

### 步骤 7:填写 superadmin 信息

superadmin 是商户号管理员，登录商户平台用:

1. **superadmin 姓名**:联系人姓名（可以是用户本人）
2. **手机号**:联系人手机号
3. **邮箱**:联系人邮箱（**注册后不能改**）
4. **验证码**:接收手机验证码并输入
5. 点击 **"下一步"**

### 步骤 8:上传补充材料

1. **场景说明**:上传 PDF 说明 IHUI-AI 项目的业务模式
   - 内容应包括:项目介绍 + 收款场景 + 退款政策
2. **截图**:网站首页截图、订单流程截图（如适用）
3. 点击 **"提交"**

### 步骤 9:等待审核

1. 页面显示"申请已提交，审核中"
2. 微信支付会在 **3-5 工作日**内审核
3. 审核结果通过邮件 / 短信通知 superadmin
4. 期间可能有微信支付客服来电核实信息

### 步骤 10:审核通过

1. 收到邮件"商户号审核通过"
2. 邮件包含:
   - **商户号 mch_id**（10 位数字）
   - **登录账号**:superadmin 邮箱
   - **初始密码**:邮件中提供
3. 登录 [https://pay.weixin.qq.com](https://pay.weixin.qq.com)

## 四、商户平台设置

### 步骤 1:登录商户平台

1. 访问 [https://pay.weixin.qq.com](https://pay.weixin.qq.com)
2. 输入 superadmin 邮箱和密码
3. 完成手机验证

### 步骤 2:设置 API v3 密钥

1. 顶部菜单 → **"账户中心"**
2. 左侧菜单 → **"API 安全"**
3. 找到 **"API v3 密钥"**
4. 点击 **"设置 API v3 密钥"**
5. 输入 32 位字符串（**自己生成**，包含字母数字）
   - 例如:`ihui2026WechatPaySecretKey9876`（32 字符）
6. **保存这个密钥到安全的地方**（不可找回）
7. 点击 **"确认"**

![设置 API v3 密钥](screenshot-placeholder)

### 步骤 3:申请 API 证书

1. 在 **"API 安全"** 页面，找到 **"API 证书"**
2. 点击 **"申请证书"**
3. 按引导下载证书工具（Windows / Mac）
4. 用工具生成证书请求文件
5. 提交请求，下载证书
6. 保存证书文件:
   - `apiclient_cert.p12`（PKCS12 格式，含私钥）
   - `apiclient_cert.pem`（PEM 格式证书）
   - `apiclient_key.pem`（PEM 格式私钥）
7. 在商户平台查看 **证书序列号**（serial number）

### 步骤 4:绑定 AppID

1. 顶部菜单 → **"产品中心"**
2. 左侧菜单 → **"AppID 账号管理"**
3. 点击 **"关联 AppID"**
4. 输入微信服务号 / 小程序的 AppID
5. 等待微信服务号管理员确认（在公众号后台）

## 五、配置到 .env

在项目的 `.env` 文件添加:

```bash
# WeChat Pay Configuration
WECHAT_PAY_APP_ID=wx用户公众号AppID
WECHAT_PAY_MCH_ID=10位商户号
WECHAT_PAY_API_V3_KEY=32位API v3密钥
WECHAT_PAY_CERT_SERIAL_NO=证书序列号
WECHAT_PAY_PRIVATE_KEY_PATH=./certs/wechat/apiclient_key.pem
WECHAT_PAY_PUBLIC_KEY_PATH=./certs/wechat/apiclient_cert.pem

# Optional: Notify URL
WECHAT_PAY_NOTIFY_URL=https://ihui.ai/api/wechat/notify
```

### 5.1 证书文件存放

1. 在项目根目录创建 `certs/wechat/` 目录
2. 把以下文件复制进去:
   - `apiclient_cert.pem`
   - `apiclient_key.pem`
3. **重要**:在 `.gitignore` 添加 `certs/`（避免提交到 git）

## 六、在项目集成

### 6.1 在 /sponsor 页面添加微信支付

1. 打开 `apps/web/src/app/(main)/sponsor/page.tsx`
2. 添加微信支付组件:

```tsx
import { WechatPayButton } from '@/components/payment/wechat-pay';

export default function SponsorPage() {
  return (
    <div>
      {/* ... */}
      <WechatPayButton amount={1} description="IHUI-AI 捐赠" />
    </div>
  );
}
```

### 6.2 后端实现 Native 支付 API

1. 打开 `apps/api/src/routes/payment/wechat.ts`
2. 实现 `/api/wechat/native` 端点:
   - 接收金额
   - 调用微信支付 Native 下单 API
   - 返回二维码 URL
3. 实现 `/api/wechat/notify` 端点:
   - 接收支付结果通知
   - 验证签名
   - 更新订单状态

## 八、手续费与结算

### 8.1 手续费

- **标准费率**:0.6% / 笔
- **特约商户**:0.38% / 笔（需行业资质）
- **公益类**:0% / 笔（需公益机构资质）

### 8.2 结算周期

- **T+1**:次日自动结算到对公账户
- **D+1**:当日结算（需开通，额外费用）
- **实时结算**:即时到账（需特殊申请）

### 8.3 提现

- 自动结算到对公账户
- 提现免费
- 对公账户转账到个人银行卡需企业操作

## 九、替代方案:个体工商户注册

如果用户没有企业资质，可注册个体工商户:

### 步骤 1:准备材料

- [ ] 身份证（原件）
- [ ] 一寸照片
- [ ] 经营场所证明（房产证 / 租房合同）
- [ ] 经营范围描述

### 步骤 2:去工商局注册

1. 到经营地所在区工商局
2. 填写《个体工商户开业登记申请书》
3. 提交材料
4. 等待审核（1-3 工作日）
5. 领取营业执照

### 步骤 3:开对公账户（可选）

个体工商户可不开对公账户，用法人个人银行卡结算。但部分场景需要:
1. 去银行开个体工商户结算账户
2. 提供营业执照 + 身份证
3. 等待开户（1-3 工作日）

### 步骤 4:用个体工商户申请微信支付

按照本指南步骤 1-10 申请微信支付商户号，主体类型选 **个体工商户**。

## 十、常见问题

### Q1:微信支付商户号审核失败怎么办？

A:常见原因:
- 营业执照照片不清 → 重新上传高清照片
- 经营类目不符 → 改为正确的类目
- 联系人电话打不通 → 提供可联系的电话
- 业务模式不清 → 补充业务说明 PDF

### Q2:小程序 vs 公众号 vs Native 支付选哪个？

A:
| 场景 | 接入方式 | 适合 |
|------|----------|------|
| 网站（PC）扫码 | Native 支付 | **IHUI-AI 推荐** |
| 手机浏览器内 | H5 支付 | 移动端网站 |
| 微信内打开网站 | 公众号支付 | 已有服务号 |
| 小程序内 | 小程序支付 | 已有小程序 |

### Q3:个体工商户与公司有什么区别？

A:
| 对比项 | 个体工商户 | 公司 |
|--------|------------|------|
| 注册成本 | 几十元 | 几百到几千元 |
| 注册时间 | 1 天 | 3-7 天 |
| 法律责任 | 无限责任 | 有限责任 |
| 税率 | 个人所得税 | 企业所得税 |
| 银行账户 | 个人卡可 | 必须对公 |
| 微信支付 | 可申请 | 可申请 |

### Q4:商户号可以申请多个吗？

A:**一个营业执照只能申请一个商户号**。如果要多个，需多个营业执照。

### Q5:微信支付与支付宝商户有什么区别？

A:
| 对比项 | 微信支付 | 支付宝 |
|--------|----------|--------|
| 费率 | 0.6% | 0.6% |
| 结算 | T+1 | T+1 |
| 申请难度 | 中等 | 中等 |
| 用户量 | 12 亿 | 9 亿 |
| 适合 | 全场景 | 电商 / 线下 |

### Q6:海外用户能扫码吗？

A:**不能**。微信支付仅支持中国大陆用户。海外用户请用 Stripe / PayPal。

## 十一、安全建议

1. ✅ **API v3 密钥妥善保管**（不可找回，丢失需重新生成）
2. ✅ **证书文件加密存储**
3. ✅ **Webhook 验证签名**（用 API v3 密钥验证）
4. ✅ **金额服务端校验**（不信任前端传的金额）
5. ❌ 不要把证书文件提交到 git
