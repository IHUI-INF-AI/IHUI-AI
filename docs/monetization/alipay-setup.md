# 支付宝商户注册指南

> **目标**:注册支付宝商户，让 IHUI-AI 项目能接受支付宝扫码支付。
>
> **难度**:⭐⭐⭐⭐ 难（**需企业资质或个体工商户执照**）
>
> **审核周期**:1-3 工作日

---

## 一、前置条件

- [ ] **营业执照**（企业或个体工商户）
- [ ] 法人身份证（正反面照片）
- [ ] **对公账户**（企业）或 法人个人银行卡（个体工商户）
- [ ] 已认证的支付宝企业账号 / 个人账号
- [ ] 联系人手机号
- [ ] 联系人邮箱

> ⚠️ **重要**:支付宝商户**必须有企业资质或个体工商户执照**。个人无法直接申请商户功能。

---

## 二、支付宝商户是什么？

**支付宝商户**让网站 / App / 小程序能接受支付宝扫码支付、JSAPI 支付、当面付等。

**优势**:
- ✅ 国内用户量大（9 亿+）
- ✅ 即时到账（T+1 结算）
- ✅ 手续费低（0.6% / 笔）
- ✅ 支持扫码 / 网页 / App 全场景

**劣势**:
- ❌ **必须企业资质或个体工商户**
- ❌ 审核 1-3 工作日
- ❌ 接入文档相对复杂

---

## 三、注册步骤

### 步骤 1:访问支付宝开放平台

1. 打开浏览器
2. 地址栏输入:[https://open.alipay.com](https://open.alipay.com)
3. 按 Enter

![访问支付宝开放平台](screenshot-placeholder)

### 步骤 2:登录或注册

1. 点击右上角 **"登录"**
2. 用已认证的支付宝账号扫码登录（企业账号）
3. 或注册新企业账号:
   - 点击 **"免费注册"**
   - 选择 **"企业账户"**
   - 填写邮箱、密码
   - 完成企业实名认证（上传营业执照）

### 步骤 3:进入控制台

1. 登录后进入 **"控制台"**（[https://open.alipay.com/dev/workspace](https://open.alipay.com/dev/workspace)）
2. 点击 **"创建应用"**

### 步骤 4:创建应用

1. **应用类型**:**网页应用**（适合 IHUI-AI）
   - 其他选项:小程序 / 移动应用 / 生活号
2. **应用名称**:`IHUI-AI 收款`
3. **应用简介**:`IHUI-AI 项目赞助与数字产品销售`
4. 点击 **"创建"**

![创建应用](screenshot-placeholder)

### 步骤 5:填写应用信息

1. **应用图标**:上传项目 logo（建议 120×120 px）
2. **应用地址**:`https://ihui.ai`
3. **应用说明**:`IHUI-AI 开源 AI 平台赞助与数字产品销售`
4. **开发者信息**:
   - 姓名 / 联系电话 / 邮箱
5. 点击 **"保存"**

### 步骤 6:添加能力

1. 在应用详情页，找到 **"能力列表"**
2. 点击 **"添加能力"**
3. 选择:
   - ✅ **电脑网站支付**（PC 端支付）
   - ✅ **手机网站支付**（移动端支付）
   - ✅ **当面付**（扫码支付）
   - ✅ **现金红包**（可选）
4. 点击 **"确定"**

### 步骤 7:签约能力

1. 添加能力后，部分需要 **签约**
2. 点击对应能力旁边的 **"签约"**
3. 填写签约信息:
   - **经营内容**:`软件开发 / 数字产品销售`
   - **营业执照**:上传
   - **网站截图**:上传 IHUI-AI 网站截图
   - **退款政策**:填写
4. 提交签约申请
5. 等待审核（1-3 工作日）

### 步骤 8:配置应用

签约通过后，配置应用:

#### 8.1 设置接口加签方式

1. 在应用详情页，找到 **"开发设置"** → **"接口加签方式"**
2. 点击 **"设置"**
3. 选择 **"公钥模式"**（推荐）或 **"证书模式"**
4. 下载 **"支付宝开放平台密钥工具"**
5. 用工具生成密钥对:
   - 应用私钥
   - 应用公钥
6. **保存应用私钥**（重要，用于后端签名）
7. 上传应用公钥到支付宝
8. **复制支付宝公钥**（用于后端验签）

![设置接口加签方式](screenshot-placeholder)

#### 8.2 设置服务器异步通知页面

1. **异步通知地址**:`https://ihui.ai/api/alipay/notify`
2. 用途:支付宝在支付成功时通知你的服务器

#### 8.3 设置同步跳转页面

1. **同步跳转地址**:`https://ihui.ai/sponsor/success`
2. 用途:用户支付完后跳回的页面

### 步骤 9:提交审核

1. 检查应用信息无误
2. 点击 **"提交审核"**
3. 等待审核（1-3 工作日）
4. 审核通过后，应用状态变为 **"已上线"**

### 步骤 10:获取 APPID

1. 在应用详情页顶部，找到 **APPID**（16 位数字）
2. 复制保存

---

## 四、配置到 .env

在项目的 `.env` 文件添加:

```bash
# Alipay Configuration
ALIPAY_APP_ID=用户的APPID
ALIPAY_PRIVATE_KEY=用户的应用私钥
ALIPAY_PUBLIC_KEY=支付宝公钥
ALIPAY_GATEWAY_URL=https://openapi.alipay.com/gateway.do
ALIPAY_NOTIFY_URL=https://ihui.ai/api/alipay/notify
ALIPAY_RETURN_URL=https://ihui.ai/sponsor/success

# Optional: Sandbox mode
# ALIPAY_GATEWAY_URL=https://openapi-sandbox.dl.alipaydev.com/gateway.do
```

## 五、在项目集成

### 5.1 在 /sponsor 页面添加支付宝按钮

1. 打开 `apps/web/src/app/(main)/sponsor/page.tsx`
2. 添加支付宝组件:

```tsx
import { AlipayButton } from '@/components/payment/alipay';

export default function SponsorPage() {
  return (
    <div>
      {/* ... */}
      <AlipayButton amount={1} subject="IHUI-AI 捐赠" />
    </div>
  );
}
```

### 5.2 后端实现支付 API

1. 打开 `apps/api/src/routes/payment/alipay.ts`
2. 实现 `/api/alipay/create` 端点:
   - 接收金额
   - 调用支付宝 alipay.trade.page.pay API
   - 返回支付页面 URL
3. 实现 `/api/alipay/notify` 端点:
   - 接收支付结果异步通知
   - 验证签名（用支付宝公钥）
   - 更新订单状态

## 七、手续费与结算

### 7.1 手续费

- **标准费率**:0.6% / 笔
- **特殊行业**:0.38% / 笔（需行业资质）
- **公益类**:0% / 笔（需公益机构资质）

### 7.2 结算周期

- **T+1**:次日自动结算到对公账户
- **D+1**:当日结算（需开通）
- **实时到账**:即时结算（特殊申请）

### 7.3 提现

- 自动结算到对公账户
- 提现免费
- 对公账户转账到个人银行卡需企业操作

## 八、常见问题

### Q1:支付宝商户与微信支付商户有什么区别？

A:
| 对比项 | 支付宝 | 微信支付 |
|--------|--------|----------|
| 费率 | 0.6% | 0.6% |
| 结算 | T+1 | T+1 |
| 申请难度 | 中等 | 中等 |
| 用户量 | 9 亿 | 12 亿 |
| 适合 | 电商 / 线下 | 全场景 |
| 文档 | 完善 | 完善 |

### Q2:海外用户能扫码吗？

A:**不能**。支付宝商户仅支持中国大陆用户。海外用户请用 Stripe / PayPal。

### Q3:个人支付宝能用吗？

A:个人支付宝账号可以收款（朋友间转账），**但不能用作商户收款**。商户收款必须有营业执照。

### Q4:支付宝商户号与 APPID 有什么关系？

A:
- **支付宝商户号**:与营业执照关联，是商户身份
- **APPID**:在开放平台创建的应用 ID，每个应用一个

一个商户号可以创建多个应用（APPID）。

### Q5:加签方式选公钥还是证书？

A:
| 方式 | 优势 | 劣势 |
|------|------|------|
| **公钥模式** | 简单，易上手 | 安全性较低 |
| **证书模式** | 安全性高 | 配置复杂 |

**推荐**:首次使用选公钥模式，安全要求高选证书模式。

### Q6:如何处理退款？

A:
1. 调用 `alipay.trade.refund` API
2. 提供订单号 + 退款金额
3. 退款原路返回
4. 手续费不退

### Q7:异步通知（notify）没收到怎么办？

A:
1. 检查服务器是否能访问外网
2. 检查 URL 是否 HTTPS（支付宝要求 HTTPS）
3. 检查防火墙是否拦截
4. 在开放平台手动重发通知

## 九、安全建议

1. ✅ **应用私钥妥善保管**
2. ✅ **支付宝公钥用于验签**（防止伪造通知）
3. ✅ **金额服务端校验**（不信任前端传的金额）
4. ✅ **订单号唯一**（防止重复支付）
5. ✅ **HTTPS 强制**（支付宝要求 HTTPS 回调）
6. ❌ 不要把私钥提交到 git
