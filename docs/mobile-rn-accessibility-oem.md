# 无障碍自动安装:各 OEM 开启路径

App 内的「开启全自动更新」依赖系统无障碍服务 `zh.ai.sq/zh.ai.sq.A11yAutoInstallService`。
AOSP/原生 Android 实测可用(模拟器 API 36);下面各 OEM 的路径**按公开资料与系统惯例整理,未逐机型实测**,
以设备实际菜单为准。判据永远以 App「设置 → 开启全自动更新」右侧的状态字为准(已启用/已禁用)。

## 判据是怎么来的(App 侧口径)

服务每 5s 写一次心跳到 `ihui_a11y` pref(键 `connectedAt`),App 只认 20s 窗口(4 倍心跳)。
三路 OR 任一为真即判开启:① 服务自报心跳新鲜;② 系统全局开关为 1 且本服务在启用清单内;
③ AccessibilityManager 报已绑定。心跳缺失即判未开启——关掉无障碍时系统不保证回调 `onUnbind`,
所以不能靠一次性写入的 `connected=true` 长期驻留。

## 通用开启路径(AOSP / Pixel / 类原生)

设置 → 无障碍(Accessibility) → 已下载的应用 / 已安装的服务 → 「IHUI 自动安装」→ 打开。
打开后回到 App,设置页那一行会显示「已启用」;若仍显示「已禁用」,下拉重进一次页面即复检。

## 小米 MIUI / HyperOS

设置 → 更多设置 → 无障碍 → 已安装的服务 → 「IHUI 自动安装」→ 打开。
另需:应用设置 → 应用管理 → 智汇 AI → 权限 → 允许「后台弹出界面」;省电策略设为「无限制」。
HyperOS 部分版本把无障碍入口收进「辅助功能」,并在关闭时会弹二次确认,需点「仍然开启」。

## 华为 EMUI / HarmonyOS

设置 → 辅助功能 → 无障碍 → 已安装的服务 → 「IHUI 自动安装」→ 打开。
另需:手机管家 → 应用启动管理 → 智汇 AI 改为「手动管理」并勾选自启动/关联启动/后台活动。

## OPPO ColorOS / vivo OriginOS / 荣耀 MagicOS

设置 → 辅助功能/无障碍 → 已安装的服务 → 「IHUI 自动安装」→ 打开。
另需在「应用自启动/后台管理」里放行智汇 AI,否则服务进程会被回收、心跳随之中断(表现为状态在几分钟后回落成已禁用)。

## 看到「受限可见 / Controlled by Restricted Setting」怎么办

这是系统层把无障碍设置交给设备管理策略(常见于共享设备、企业管控、或 `adb` 安装后被策略接管)。
个人设备上通常是「设置被另一个用户/工作资料共享」:在 设置 → 系统 → 多用户 里确认当前用户,
或用 adb 覆盖安装一次(`adb install -r`)即可解除(实测有效)。设备由 MDM 管控时只能找管理员放行。

## 验证是否真的生效

1. App 设置页该行显示「已启用」;
2. `adb shell settings get secure enabled_accessibility_services` 含 `zh.ai.sq/zh.ai.sq.A11yAutoInstallService`;
3. `adb shell dumpsys accessibility` 的 `Bound services` 里出现 `label=IHUI 自动安装`;
4. App 日志 `[ihui-auto-install:raw]` 的 `selfReported/bound/enabled` 三项为 true。
