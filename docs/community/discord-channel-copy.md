## 2. #功能介绍·features

```
# ✨ 功能介绍

**一个入口，118 个大模型**
DeepSeek、通义、Kimi、GLM、GPT、Claude、Gemini、Llama 等 118 个模型统一接入，LiteLLM 网关做路由与降级，一个账号全都能用，不用再开一堆会员。

**Agent 编排**
LangGraph 工作流 + MCP 工具调用 + A2A 智能体互联。多步任务自动拆解：查资料 → 调工具 → 出结果，不只是聊天。

**知识库问答（RAG）**
上传 PDF / Word / 网页，pgvector 向量检索，回答带原文出处。

**全模态**
文字、图片、视频、语音统一入口，语音可实时对话。

**多端同源**
Web（Next.js 16）、桌面（Tauri 2）、Android / iOS（React Native + Expo）、小程序（Taro 4）、浏览器插件（MV3）、CLI —— 8 个端共享同一套内核，数据互通。

**可直接商用**
多租户 + 行级安全 + 计费 + 额度 + 教育全栈，开箱即用；Apache-2.0 可自建可二开。

想要什么功能 → 去 #问题反馈·feedback 说，能做的排进版本。
```

## 3. #技术栈·tech-stack

```
# 🛠 技术栈

**后端 API**：Node 20 + Fastify 5 + TypeScript · Drizzle ORM + PostgreSQL 15（pgvector）· Zod 校验 · 4,451 条路由 · 25 个 WebSocket 端点 · 599 张表
```
