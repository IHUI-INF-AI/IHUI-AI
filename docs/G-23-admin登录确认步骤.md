# 生产 admin 登录确认步骤（G-23 收尾单页）

> 用途：2026-10-28 离线取证确认库里现役 admin 散列已**不再命中**仓内公开默认口令，但现役口令对
> 仓内所有登记处（备份文件 / 服务环境块）都不匹配 ⇒ 需要你验证"你手里那把钥匙还能开门"。
> **全程不需要、也不应该在任何聊天/文档里写出口令明文。**

## 第 1 步 · 真机登录验证（2 分钟，你自己做）

1. 浏览器打开 `https://www.aizhs.top`（或本机 `http://127.0.0.1:8801`）。
2. 用 `admin` + **你认为现在的现役口令**登录管理后台。
3. ⚠️ **只试一次，失败就停**：账号锁定策略是 15 分钟内 5 次失败 ⇒ 锁 15 分钟，反复试会把问题
   从"口令不对"升级成"账号锁死"。

## 第 2 步 · 按结果二选一

### A. 登录成功 ⇒ G-23 彻底结清，只需补归档

现役口令只存在你脑子里，风险可接受；但仓内两处记录是陈旧的，需要换新（任选一种）：

- 把现役口令写入权威备份（PowerShell 7，不回显）：
  ```powershell
  Read-Host '粘贴现役口令' -AsSecureString | ForEach-Object {
    $plain = [System.Net.NetworkCredential]::new('', $_).Password
    [System.IO.File]::WriteAllText('D:\DevEnv\secrets\admin-password.txt', $plain)
    $plain = $null
  }
  ```
- 写完后跑回归（应绿）：
  ```powershell
  node D:\IHUI-AI\scripts\check-credential-health.mjs
  ```
  这一步同时消掉现在那条 RED（IHUI-DEPLOYLOOP 环境块 ≠ 权威源）。若不顺手修环境块，部署环健康
  门禁每次白烧 1–2 次失败登录（耗锁定预算）——修法同样是把 `IHUI_ADMIN_PASSWORD` 更新成现值。

### B. 登录失败（401/提示口令错误）⇒ 需要轮换一次，agent 可代跑

**不要在失败后继续重试。** 把下面这条发给 Loomy 代执行即可（会打印一次性新口令，请立即保存到
密码管理器并同步写入上面两处）：

```
按 PROJECT_PLAN G-23 票面五步执行生产 admin 轮换：
备份旧散列 → db:migrate → reset:admin-password --generate --force --yes
→ verifyPassword 离线复验 → 失败则用留痕散列回滚
```

器物侧护栏已内置：`NODE_ENV=production` 必须显式 `--force`、必须 `--yes`、触发器保护自动禁用又
恢复（2026-09-14 生产实测路径）、成功后只打印用户名/邮箱，散列不入库。
