## 二、可用性定义

### 2.1 计算公式

```
月度可用性 = (月度服务总分钟数 - 月度不可用分钟数) / 月度服务总分钟数 × 100%
```

### 2.2 服务总分钟数

按自然月计算(每月 1 日 0:00 至月末 23:59,UTC+8 时区),每月最大为 44,640 分钟(31 天)或 43,200 分钟(30 天)。

### 2.3 不可用(Outage)定义

满足以下**全部**条件,计为不可用:

1. 客户通过正常手段(Web/API)无法访问服务
2. 错误率(5xx)持续 ≥ 5 分钟
3. 故障原因属于厂商责任范围(见 §6 免责条款排除项除外)
4. 客户已通过工单 / 热线正式报告

### 2.4 不可用分钟数

从客户报告时间起,到故障完全恢复(全部服务可用)截止。恢复后厂商工单系统更新状态为"已解决"。

### 2.5 监控与统计

- **监控工具**:UptimeRobot + 自研拨测(每 60 秒)
- **监控页面**:<https://status.ihui-ai.com>(公网可访问)
- **第三方报告**:可申请第三方机构(听云 / 博睿)出具可用性报告

## 三、故障响应与恢复

### 3.1 响应时效

| 严重等级 | 定义 | 标准级 | 增强级 | 旗舰级 | 行业级 |

| **P3(低)** | 体验问题 / 优化建议 | ≤ 72h | ≤ 48h | ≤ 24h | ≤ 24h |

### 3.2 严重等级判定

- **P0**:全部服务 / 全部用户受影响(如 API 整体宕机)

- 持续 8 小时未恢复通知公司高管并启动客户告知

## 五、违约责任与赔偿

### 5.1 赔偿方式

当月度可用性**未达**对应等级目标时,按以下规则补偿:

| 实际可用性 | 赔偿比例(月费) |
|------------|----------------|
| 99.0% - 99.9% | 5% |
| 95.0% - 99.0% | 10% |
| 90.0% - 95.0% | 20% |
| < 90.0% | 30%(上限) |

### 5.2 赔偿计算示例

- 客户 A 购买旗舰级,年费 ¥300,000(月度分摊 ¥25,000)
- 当月实际可用性 98%(低于 99.99% 目标,落入 95-99% 区间)
- 赔偿:¥25,000 × 10% = ¥2,500(下月账单抵扣或现金返还)

### 5.3 赔偿上限

单月赔偿**不超过当月服务费的 30%**,年度赔偿**不超过年度服务费的 50%**。但客户可因持续严重违约解除合同并要求退款。

### 5.4 赔偿申请

- 客户需在不可用事件结束后 **30 天内**提出申请
- 提供:不可用时间段(工单 / 邮件 / 电话记录)+ 业务影响说明
- 厂商 5 个工作日内审核,15 个工作日内执行

### 5.5 不可抗力排除

以下情况**不计入**不可用时间,也不构成厂商违约:

- 客户自身网络 / 设备 / 配置问题
- 客户应用程序 / 客户端代码 bug
- 第三方云厂商 / LLM 厂商故障(且厂商已配置多源备份)
- 不可抗力(地震 / 战争 / 政府行为 / 重大公共卫生事件)
- 客户授权的维护窗口
- 客户超量使用(超出套餐 QPS / 调用量)导致的服务降级
- 客户未及时安装安全补丁导致的漏洞
- 客户数据丢失(超出厂商备份保留期限)
- 攻击行为(除非厂商侧防御失效)

- **RPO(恢复点目标)**:旗舰级 ≤ 5min,增强级 ≤ 30min,标准级 ≤ 24h
- **RTO(恢复时间目标)**:旗舰级 ≤ 1h,增强级 ≤ 4h,标准级 ≤ 24h

所有客户数据**100% 归客户所有**,厂商无权访问 / 复制 / 转授第三方。合同终止后,客户可导出全部数据,30 天后厂商**不可逆**删除。

### 6.4 数据主权

- 私有云 / 混合云:数据完全在客户侧,厂商无任何访问权限
- 公有云:数据存储在客户选择的云厂商地域(中国大陆 / 港澳台 / 海外),按客户指定
