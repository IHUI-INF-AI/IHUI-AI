## 一、社区是什么

**智汇 AI 社区**(International Hub of Unified Intelligence AI Community)是基于 Apache 2.0 开源项目 **IHUI-AI** 构建的智能体创作者经济平台。

与传统的"AI 聊天工具"或"AI 编程助手"不同,智汇 AI 社区的核心定位是**让任何用户创建的智能体能上架、被订阅、被交易、产生收入**。

### 核心理念

- **智能体 = 数字商品**:像 App Store 里的 App 一样,可被定价、上架、订阅、评分
- **创作者 = 开发者**:任何人(不一定要会写代码)都能用低代码方式创建智能体
- **平台 = 撮合者**:平台提供流量、技术基础设施、支付通道,创作者拿 70% 分成

## 二、社区能做什么

### 2.1 对普通用户(消费者)

- **订阅智能体**:月费 ¥9-¥99,无限次使用平台上的优质智能体
- **按调用付费**:用一次付一次费(¥0.1-¥5/次),适合低频高价值需求
- **免费试用**:大部分智能体提供 5-20 次免费试用额度
- **跨端使用**:Web / iOS / Android / 微信小程序 / Chrome 扩展,任一端订阅全端通用

### 2.2 对创作者(生产者)

- **低代码创建智能体**:拖拽式画布编辑,无需编程基础也能创建专业智能体
- **多种定价模式**:
  - 免费(Free):引流,积累用户口碑
  - 订阅(Subscription):月费/年费,稳定收入
  - 按调用(Per Call):用一次付一次,适合工具型
  - 分成(Revenue Share):创作者 70% / 平台 30%
- **沙箱测试**:发布前自动跑 50 条评估用例,质量不达标无法上架
- **数据看板**:实时查看订阅数 / 调用量 / 收入 / 用户反馈
- **创作者激励**:月度 Top 10 创作者获得官方流量扶持 + 现金奖励

### 2.3 对企业/团队(B2B)

- **私有化部署**:整套 IHUI-AI 系统可私有化部署在企业内网
- **API 集成**:通过 OpenAI 兼容 API 直接接入企业现有系统
- **定制开发**:专业工程师团队支持智能体定制(¥30,000 起)
- **数据安全**:数据完全可控,符合等保三级 / GDPR / CCPA 要求

## 六、社区运营机制

### 6.1 智能体质量评估

每个上架智能体都有**四维加权评分**(0-5 星):

| 维度 | 权重 | 计算方式 |
|------|------|----------|
| 任务成功率 | 40% | LLM-as-Judge 自动评估 |
| 用户评分 | 25% | 真实用户打分(过滤异常分布) |
| 响应延迟 | 15% | 首 token 时延 + 总时长 |
| 稳定性 | 20% | 错误率 + 重试率 |

搜索排序按这个分数排,不只按热度,避免同质化与刷分。

### 6.2 创作者激励

- **新星奖**:月度首次上架智能体且评分 ≥ 4.5,奖励 ¥500
- **Top 10 月榜**:月度收入 Top 10,获得官方流量扶持(首页推荐位 + 推送通知)
- **年度评选**:年度最佳创作者,奖励 ¥50,000 + 全平台推广
- **社区贡献**:为平台贡献代码 / 文档 / 翻译,获得贡献积分(可兑换平台服务)

### 6.3 安全保障

- **数据加密**:所有用户数据 AES-256 加密存储
- **内容审核**:智能体输出接入敏感词过滤 + LLM 安全审查
- **支付合规**:通过 PCI-DSS 认证,支持微信支付/支付宝/Stripe
- **隐私保护**:符合《个人信息保护法》+ GDPR + CCPA

## 八、常见问题

**Q1:智汇 AI 社区是免费的吗?**

A:基础会员 ¥39/月,可使用大部分智能体。专业会员 ¥99/月,解锁全部智能体 + 高级模型。创作者分成:创作者 70%,平台 30%。

**Q2:不会写代码能创建智能体吗?**

A:可以。社区提供拖拽式画布编辑,无需编程基础。高级用户可使用代码模式(Python/TypeScript),功能更强。

**Q3:智能体能调用哪些大模型?**

A:目前支持 176 个大模型,包括 OpenAI GPT-4o/4-Turbo、Anthropic Claude 3.5/3.7、Google Gemini 2.0、文心一言、通义千问、DeepSeek、Kimi、豆包、智谱、Ollama 本地模型等。

**Q4:数据安全吗?**

A:所有用户数据加密存储,符合等保三级/GDPR/CCPA。私有化部署版本数据完全在企业内部,不经过平台。

**Q5:能退款吗?**

A:订阅 7 天内未使用可全额退款,使用后按已使用天数比例退款。按调用付费不支持退款(已消耗算力)。

**Q6:如何成为 Top 10 创作者?**

A:持续上架高质量智能体(评分 ≥ 4.5),积累用户口碑与收入。平台每月根据收入 + 评分 + 用户增长综合排名。
