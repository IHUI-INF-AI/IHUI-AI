## 选型建议

- **个人 / 极客 / 小团队**:社区版(免费,自部署,8 端全功能)
- **5-50 人创业团队**:Starter(5 万/年,免去运维,SaaS 即用)
- **50-200 人成长型企业**:Business(10 万/年,多租户 + 全 AI 厂商 + 全端)
- **200+ 人 / 强合规企业**:Enterprise(30 万/年,私有化 + 专属客户经理 + SLA 99.9%)
- **金融 / 政府 / 大型集团**:Custom(50 万+/年,源码交付 + 国密 + 完全自主可控)
