# R8 真实 Browser Hub 会话 · 画中画收起/展开/重开真机自证（2026-11-26）

## 结论

真实登录态下，Tauri 画中画窗（非 mock）完成一轮完整回归：

- 打开后客户区 `630×420`（外框 `652×433`，DPI 1.5）
- 收起后客户区 `630×48`（32px 逻辑高度 × 1.5）
- 再展开恢复 `630×420`
- 在收起态关闭，重开后仍为 `630×420`，与展开高度差 `0px`

`authMode=real-login`，使用的是线上真实账号签发的 access token 与真实 Browser Hub 会话，不是占位 token。

## 复现命令

```powershell
# 1) 线上真实登录态取一次 access token（页面内 refresh，不落盘、不写入仓库）
# 2) 以真实 token 启动桌面 R8 自检（窗口真实创建、真实收起/展开/关闭/重开）
$env:IHUI_R8_SELFTEST='1'
$env:IHUI_R8_SELFTEST_OUT='C:\IHUI-Build\r8-selftest-result.json'
$env:IHUI_R8_ACCESS_TOKEN='<运行时注入，禁止提交>'
cargo run --features r8-selftest
```

自检入口只在 `--features r8-selftest` 下编译，生产默认构建不包含该入口；
它不依赖鼠标点击，也不使用 Tauri `MockRuntime`（mock 的 `set_size` 是空实现，无法证明真实几何）。

## 原始读数

见同目录 `r8-real-window-selftest-2026-11-26.json`：

```json
{
  "authMode": "real-login",
  "session": "e3baccfb-e637-47f1-a33e-7c16cb08958c",
  "scaleFactor": 1.5,
  "before": { "width": 630, "height": 420 },
  "collapsed": { "width": 630, "height": 48 },
  "expanded": { "width": 630, "height": 420 },
  "reopened": { "width": 630, "height": 420 },
  "heightDelta": 0,
  "ok": true
}
```

## 判据与边界

- 收起态判据：`inner_height ≤ 40 × scale`；实测 `48 ≤ 60`，通过。
- 展开/重开判据：`inner_height ≥ 200 × scale`；实测 `420 ≥ 300`，通过。
- 重开一致性判据：`|reopened − expanded| ≤ 2px`；实测 `0px`，通过。
- 本证据证明的是**真实窗口的几何状态机**；`authMode=real-login` 证明开窗时使用的是真实登录 token 与真实 Browser Hub 会话。
- 生产安装包侧：同版本安装包已由桌面构建链产出；本自检入口不编入生产包，避免把测试开关带进用户安装物。
