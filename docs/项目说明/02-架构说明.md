# IHUI-AI 架构说明

> 本文档是系统架构的简明导读，完整细节请参见 [docs/architecture.md](../architecture.md)。

---

## 1. 架构总览

IHUI-AI 采用**分层微服务 + Monorepo** 架构：

```
┌─────────────────────────────────────────────────────────┐
│                      客户端层                            │
│  Web(Next.js) │ Desktop │ Mobile(RN) │ 小程序(Taro)     │
│  CLI │ Extension │ SDK(TS/Go/Java)                       │
└───────────────────────────┬─────────────────────────────┘
                            │ HTTP / WebSocket / SSE
┌───────────────────────────▼─────────────────────────────┐
│                      网关层 (Nginx)                      │
│         HTTPS 终止 / 路由 / 限流 / 安全头                 │
└───────────────────────────┬─────────────────────────────┘
                            │
        ┌───────────────────┴───────────────────┐
        ▼                                       ▼
┌───────────────────┐               ┌─────────────────────┐
│  apps/api (8802)  │   共享 JWT    │  apps/ai-service     │
│  Fastify + Drizzle│◄────────────►│  (8803) FastAPI      │
│  业务管理 + 认证   │   SSO        │  AI 推理网关         │
│  + WebSocket      │              │  LangGraph + LiteLLM │
└────────┬──────────┘               └──────────┬──────────┘
         │                                      │
         ▼                                      ▼
┌───────────────────┐               ┌─────────────────────┐
│  PostgreSQL (5432)│               │  Redis (6379)       │
│  pgvector 向量检索 │               │  缓存 / 队列 / Pub- │
└───────────────────┘               │  Sub (WS 广播)      │
                                    └─────────────────────┘
```

### 为什么拆分两个 App

| 决策 | 原因 |
|---|---|
| Python 做 AI 推理 | LangGraph（状态机工作流）、LiteLLM（多模型统一接口）、MCP 协议原生支持 |
| TypeScript 做业务 | Fastify 性能 + Drizzle 类型安全 + 共享 Zod schema，覆盖 web/api/cli/desktop |
| 协议分层 | SSE（Agent 流式）+ WebSocket（聊天室/多模型流式）+ HTTP REST（同步业务） |
| SSO 跨服务 | 共享 `JWT_SECRET`，两 app 通过 `@ihui/auth` 共享包统一签发/验证 |

## 2. 前端架构（apps/web）

- **框架**：Next.js 16 + React 19（App Router + RSC）
- **构建**：Turbopack（开发）+ Webpack（生产 standalone）
- **样式**：Tailwind CSS 4 + shadcn/ui
- **状态**：
  - 服务端状态 → `@tanstack/react-query`
  - 客户端状态 → Zustand（`src/stores/`）
- **i18n**：`next-intl`（zh-CN + en 双语）
- **通知**：`sonner` toast
- **图标**：`lucide-react`

### 前端目录结构

```
apps/web/
├── app/            # Next.js App Router 页面（en/ login/ status/ 等）
├── src/
│   ├── api/        # API 客户端封装
│   ├── i18n/       # 国际化请求
│   ├── lib/        # 工具库（ai-media / api / blog / download / feedback 等）
│   └── stores/     # Zustand 状态（auth / chat / hooks / mode / rules / theme / user）
├── e2e/            # Playwright E2E 测试
└── public/         # 静态资源（favicon / llms.txt / sw.js / 各厂商 txt）
```

### 关键设计决策

- **禁止**在客户端组件中直接 fetch，统一走 `src/lib/api.ts` 封装
- 聊天流式输出：AI 对话走 SSE（ai-service），聊天室走 WebSocket（api）
- PWA：`sw.js` 服务 Worker 提供离线缓存

## 3. 后端 API 架构（apps/api）

- **框架**：Fastify 5.1 + TypeScript（strict）
- **ORM**：Drizzle ORM 0.38 + postgres-js（340 张表）
- **认证**：`@ihui/auth`（JWT HS256 + token-family 旋转 + refresh 黑名单 + OAuth2 + 2FA + RBAC + DataScope）
- **验证**：Zod 3.24
- **日志**：Pino 9.5 + pino-pretty
- **加密**：AES-256-GCM（credentials 加密）+ bcryptjs（密码哈希）

### 路由分组（`src/routes/`）

| 领域 | 文件 | 说明 |
|---|---|---|
| 认证 | `auth.ts` / `mfa.ts` | 登录 / 注册 / OAuth2 / 2FA |
| 聊天 | `chat.ts` | 对话 + WebSocket 多模型流式 |
| 智能体 | `crew.ts` / `agents` | Agent 业务管理 |
| Coze | `coze.ts` | Coze SDK 代理 |
| 文件 | `files.ts` / `oss.ts` | 文件上传 / 对象存储 |
| 订单 | `order.ts` | 微信支付 V3 |
| 用户 | `user.ts` / `users.ts` / `admin.ts` | 用户管理 / RBAC |
| 学习 | `learn.ts` / `exam.ts` / `srs.ts` | 教育 + 考试 + 间隔复习 |
| 广场 | `plaza.ts` / `topic.ts` / `news.ts` | 社区 / 话题 / 资讯 |
| 积分 | `point.ts` | 积分体系 |
| 推送 | `push.ts` / `mail.ts` | 通知 / 邮件 |
| 审计 | `audit.ts` | 操作日志 |
| 调试 | `debug.ts` | 开发用调试端点 |

### WebSocket 端点

- 聊天室（多用户实时消息）
- 多模型流式（豆包/通义/智谱/DeepSeek/Qwen-Omni）
- WS 鉴权：`@ihui/auth` ws-auth（token 通过 query param 或首帧传递）

### 可观测性

- **OpenTelemetry**：`OTEL_ENABLED` 控制，OTLP 导出
- **Prometheus**：`/metrics` 端点，`PROMETHEUS_ENABLED` 开关
- **结构化日志**：Pino，生产 JSON / 开发 pino-pretty

## 4. AI 服务架构（apps/ai-service）

- **框架**：FastAPI 0.115 + Uvicorn
- **AI 编排**：LangGraph 0.2（StateGraph 工作流：plan → execute → summarize）
- **LLM 网关**：LiteLLM（统一 100+ 模型厂商接口，stub 模式无 key 时返回 mock）
- **MCP**：MCP SDK（11 工具 + 3 资源 + 3 提示词）
- **A2A**：Agent-to-Agent 协议（Redis 持久化 + 内存降级）
- **向量记忆**：嵌入 + 余弦相似度语义搜索

### 目录结构

```
apps/ai-service/
├── app/
│   ├── main.py          # FastAPI app 入口，注册 6 个 router + CORS
│   ├── routers/        # HTTP 路由（chat / agents / files / images / tools / user 等）
│   ├── services/
│   │   ├── langgraph_service.py  # LangGraph 工作流
│   │   ├── llm_gateway.py        # LiteLLM 多模型网关
│   │   ├── mcp_server.py         # MCP 工具/资源/提示词
│   │   ├── a2a_service.py       # A2A 协议
│   │   └── vector_memory.py     # 向量记忆
│   └── core/           # 配置 / 日志 / 安全
├── tests/              # pytest（13 文件，400 用例）
├── Dockerfile
└── .env.example
```

### Stub 模式

无 API key 时 LiteLLM 网关自动降级为 stub 模式，返回 mock 响应，便于开发测试。

## 5. 数据层架构

### 数据库

- **单库设计**：PostgreSQL 15，单库 `ihui`，通过 schema 隔离业务域
- **向量检索**：pgvector 扩展，用于 RAG 和语义搜索
- **连接**：`DATABASE_URL` 环境变量，postgres-js 驱动

### Drizzle Schema（`packages/database/src/schema/`）

覆盖 34 个业务域，共 340 张表：

```
users / projects / files / notifications / billing / audit / chat /
teams / rbac / workflow / comments / promotions / gamification /
content / system / social / community / learn / exam / order / live /
member / resource / point / usercenter / schedule / statistics /
message / topic / behavior / visit-tracking / oss / setting
```

### 迁移管理

- 目录：`packages/database/drizzle/`
- 文件：32 个 SQL 文件（`0000` ~ `0031`），144 个迁移
- 应用：`pnpm --filter @ihui/database db:migrate`
- 校验：`pnpm --filter @ihui/database db:check`

### RLS（行级安全）

`packages/database/src/rls.ts` 提供行级安全策略，支持多租户数据隔离。

## 7. 认证与授权（@ihui/auth）

全链路认证能力：

1. **JWT HS256**：签发 + 验证，token 有效期 `JWT_EXPIRES_IN`（默认 7d）
2. **Token-Family 旋转**：access token 过期后 refresh token 旋转，旧 refresh 进入黑名单
3. **Refresh 黑名单**：Redis 存储，登出 / 旋转后立即失效
4. **密码哈希**：bcryptjs（SHA256 兼容旧 Java 平台数据）
5. **OAuth2 PKCE**：飞书 / Coze / 微信 / 钉钉 / 企业微信扫码登录
6. **2FA**：TOTP + 短信
7. **RBAC**：基于角色的访问控制
8. **DataScope**：数据范围隔离（多租户）
9. **API Key / PAT / 用户 SK**：程序化调用凭证

## 9. 安全架构

### HTTP 安全头（由 `security-service.ts` 统一配置）

| 安全头 | 值 |
|---|---|
| `Strict-Transport-Security` | `max-age=31536000; includeSubDomains` |
| `Content-Security-Policy` | `default-src 'self'; script-src 'self' 'unsafe-inline'; ...` |
| `X-Content-Type-Options` | `nosniff` |
| `X-Frame-Options` | `DENY` |
| `Referrer-Policy` | `strict-origin-when-cross-origin` |
| `Permissions-Policy` | `geolocation=(), microphone=(), camera=()` |

### 其他安全措施

- **CSRF**：`@fastify/csrf` 插件
- **CORS**：`CORS_ORIGIN` 白名单（单数）
- **凭证加密**：AES-256-GCM
- **限流**：`@fastify/rate-limit`
- **mTLS**：`plugins/mtls.ts`（可选）
- **审计日志**：所有敏感操作记录到 `audit` 表

完整安全策略请参见 [docs/SECURITY.md](../SECURITY.md)。

## 10. 多端架构（MULTI_END）

| 端 | 目录 | 技术 |
|---|---|---|
| Web | `apps/web` | Next.js 16 + React 19 |
| API | `apps/api` | Fastify 5 + TS |
| AI 服务 | `apps/ai-service` | FastAPI + LangGraph |
| CLI | `apps/cli` | Node.js + TUI |
| Desktop | `apps/desktop` | Electron |
| 浏览器插件 | `apps/extension` | WXT |
| 移动端 | `apps/mobile-rn` | React Native + Expo |
| 小程序 | `apps/miniapp-taro` | Taro（微信/支付宝/抖音） |

各端通过共享 `@ihui/types` + `@ihui/sdk` 保持类型一致，API 调用走统一 HTTP/WS 协议。
