# IHUI-AI 项目总览

> 本文档是 IHUI-AI 项目的快速入门概览，帮助开发者在 5 分钟内了解项目全貌。
> 完整文档请参见 [docs/README.md](../README.md)。

---

## 1. 项目简介

IHUI-AI（智汇AI）是一个**全栈 AI 平台**，采用 TypeScript Monorepo 架构，提供对话、Agent、RAG、图像/视频/3D 生成、记忆、MCP 工具等完整 AI 能力。

- **开源协议**：Apache 2.0（可商用、可修改、可分发）
- **目标用户**：开发者、AI 平台运维、全栈工程师

---

## 2. 技术栈一览

| 层面 | 技术选型 | 说明 |
|---|---|---|
| 包管理 | pnpm 9.15 + Turborepo 2.3 | Monorepo workspace，增量构建 |
| 运行时 | Node.js ≥ 20.10.0 | 全端 JS 运行时 |
| 后端 API | Fastify 5.1 + TypeScript | 高性能 HTTP 服务，端口 8802 |
| ORM | Drizzle ORM 0.38 + postgres-js | 类型安全 SQL 生成，340 张表 |
| 数据库 | PostgreSQL 15（pgvector） | 向量检索 + 业务数据 |
| 缓存/队列 | Redis 7 | 缓存、BullMQ 队列、WebSocket Pub/Sub |
| 前端 Web | Next.js 16 + React 19 + Tailwind CSS 4 + shadcn/ui | 端口 8801 |
| AI 服务 | FastAPI + LangGraph + LiteLLM + MCP | Python 推理网关，端口 8803 |
| 认证 | @ihui/auth（JWT HS256 + OAuth2 + 2FA + RBAC） | 跨服务 SSO |
| 状态管理 | @tanstack/react-query + Zustand | 前端状态 |
| 国际化 | next-intl（zh-CN + en） | 双语支持 |
| 测试 | Vitest + Playwright E2E + pytest + Locust | 分层测试金字塔 |
| 可观测性 | OpenTelemetry + Prometheus + Grafana + Jaeger | 全链路追踪 |

## 3. 项目结构

```
IHUI-AI/
├── apps/
│   ├── web/            # Next.js 16 前端（端口 8801）
│   ├── api/            # Fastify 5 后端 API（端口 8802）
│   ├── ai-service/     # Python FastAPI AI 推理网关（端口 8803）
│   ├── cli/            # 命令行工具
│   ├── desktop/        # 桌面端（Electron）
│   ├── extension/      # 浏览器插件（WXT）
│   ├── mobile-rn/      # React Native 移动端
│   └── miniapp-taro/   # Taro 小程序（微信/支付宝/抖音）
├── packages/
│   ├── auth/           # @ihui/auth — JWT / OAuth2 / RBAC / WS 鉴权
│   ├── database/       # @ihui/database — Drizzle schema（340 表）+ 144 迁移
│   ├── types/          # @ihui/types — 共享类型定义
│   ├── sdk/            # @ihui/sdk — 多语言 SDK（TS/Go/Java）
│   ├── i18n/           # @ihui/i18n — 国际化
│   ├── shared/         # @ihui/shared — 共享工具
│   └── app/            # @ihui/app — 应用配置
├── deploy/             # Docker / Nginx / CDN / SaaS 部署脚本
├── docs/               # 完整文档（本目录）
├── scripts/            # 自动化脚本（守门、CI、部署）
├── benchmarks/         # 性能基准测试
└── monitoring/         # 监控配置
```

### 核心两个 App 的职责分工

| App | 技术栈 | 职责 | 端点数 |
|---|---|---|---|
| `apps/api` | TS Fastify + Drizzle | 业务管理 + 多厂商代理 + 认证 + WebSocket | 4393 |
| `apps/ai-service` | Python FastAPI + LangGraph | AI 推理网关（LLM 调用、Agent 执行、MCP 工具、A2A 协议） | ~55 |

> ⚠️ 审计 AI 能力迁移时，**必须同时看两个 app**，仅看单一 app 会得出错误结论。

## 4. 关键脚本速查

| 命令 | 用途 |
|---|---|
| `pnpm install` | 安装所有 workspace 依赖 |
| `pnpm dev` | 启动所有服务（web + api + ai-service） |
| `pnpm --filter @ihui/web dev` | 仅启动前端 |
| `pnpm --filter @ihui/api dev` | 仅启动后端 API |
| `cd apps/ai-service && uv run uvicorn app.main:app` | 仅启动 AI 服务 |
| `pnpm --filter @ihui/api test` | 运行后端单元测试 |
| `pnpm --filter @ihui/web test:e2e` | 运行 Playwright E2E 测试 |
| `docker compose up -d` | 启动 db + redis + 全栈 |
| `pnpm --filter @ihui/database db:migrate` | 应用数据库迁移 |
