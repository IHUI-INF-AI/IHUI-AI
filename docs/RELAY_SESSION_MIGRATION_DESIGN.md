# WorkBuddy 会话搬家设计定案(⑦第二刀前置 · 2026-10-27)

> 本文是⑦「会话搬家」写操作链的**设计定案**。取证事实见
> `docs/RELAY_SESSION_MIGRATION_EVIDENCE.md`(本目录,同日)。
> 定案前决不施工任何写面;本文批准前,仓内只有只读盘点(`pnpm relay:sessions`)
> 与备份(`pnpm relay:sessions:backup`)两腿,二者对会话库**零写入、零删除**。

## 1. 目标与范围

把 WorkBuddy 助手本机会话库(`~/.workbuddy/workspace/sessions/`、
`~/.workbuddy/projects/` 下转写)按账号隔离/搬移,对标 wb-switch 的能力面:

- 备份(已落地):全量快照到 `~/.wb-switch/backups/sessions/<时间戳>/`,带 sha256 清单。
- 恢复(设计票):从快照回填,`manifest.json` 逐文件 sha256 校验,任何 mismatch 拒绝继续。
- 搬移/隔离(设计票,依赖恢复腿 + 账号关联模型):按账号建会话分桶台账。

## 2. 红线(任何写面实现必须全部满足,违一即停)

1. **备份先行**:任何改动会话库的命令,第一步必须产出当日快照;当日快照已存在则校验后复用,不重复拷贝。
2. **预览先行**:所有写面命令默认 dry-run,只打印将动文件清单(路径+字节数,不打印内容);真写必须显式 `--apply`。
3. **逐条可撤**:每轮写操作生成操作日志(`manifest.json` + `ops.jsonl`),记录动前动后状态;恢复腿必须能按单条操作回退。
4. **零内容回显**:日志/预览/错误信息永不包含 token、消息正文;只出现路径、字节数、sha256。
5. **校验后收工**:拷贝/回填后逐文件 sha256 对账,数量与字节双重核对;对不上即报错退出,不留半写状态(先写临时名,全量校验过后再原子改名)。
6. **源只读**:盘点/备份腿对源目录只 `readFileSync`/`statSync`,绝不 `write`/`unlink`/`rename` 源侧任何路径。

## 3. 已落地两腿

| 腿 | 命令 | 面 | 状态 |
|---|---|---|---|
| 盘点 | `pnpm relay:sessions` | 只读,三面盘点+隔离判定 | 2026-10-27 入库 |
| 备份 | `pnpm relay:sessions:backup` | 源只读 → 快照拷出,默认 dry-run | 2026-10-27 入库 |

备份产物形状:

```
~/.wb-switch/backups/sessions/20261027T021500Z/
  manifest.json   # { createdAt, source: {sessionsRoot, projectsRoot}, files: [{rel, bytes, mtimeMs, sha256}] }
  workspace/sessions/<uuid>/...   # 会话目录原样镜像
  projects/<ws>/...jsonl          # 转写原样镜像
```

## 4. 恢复腿设计(未施工)

- 输入:快照目录 + 目标根(默认原源根;`--dest` 可指他处做"搬家到另一台机/另一目录")。
- 流程:dry-run 列差异(目标缺失/内容不一致,按 sha256 比)→ `--apply` 时逐文件先写
  `<file>.restoring-<ts>` 临时名 → sha256 校验 → 原子 rename 覆盖 → 全量对账收工。
- 拒绝场景:目标存在且 sha 不一致且未显式 `--force`(宁可拒做,不静默覆盖);
  manifest 缺失或 sha256 字段缺失(旧格式快照不认)。

## 5. 搬移/隔离设计(未施工,依赖两前置)

- 前置一:恢复腿收工(可撤能力的载体)。
- 前置二:**账号↔会话关联模型定案**——当前会话库无按账号分桶标记(取证记录 §4);
  候选方案 A:按 `accounts.json` + 切换时刻分桶(切换后新增会话归新账号,存量归"未归属");
  方案 B:人工标注台账。两者都要求隔离台账(`*_session_links.json` 同形)先建、后动。
- 施工顺序:台账建 → 试运行单会话搬移(可撤) → 抽样校验 → 全量。任一步失败按操作日志回退。

## 6. 开放问题(施工前必须拍板)

1. 方案 A/B 二选一(建议 A:机器可判,存量显式标"未归属"不猜)。
2. 搬移粒度:整库 / 按工作区 / 单会话(建议:最小粒度单会话,逐条可撤)。
3. `projects/` 转写与会话目录的关联键(conversationId ↔ workspace 路径映射)需在
   施工前用真实数据抽样验证一次(只读核实,不属写面)。
