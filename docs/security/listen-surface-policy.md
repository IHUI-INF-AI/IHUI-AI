# 监听面基线策略评审清单（RP-6 / L15）

> 立档 2026-11-26。对应 `PROJECT_PLAN.md` RP-6（L15/P0）"监听面基线"。
> 静态守门：`scripts/check-listen-baseline.mjs`（判据 P1 钉住本文件的组合禁令句）。

## 适用范围

生产服务的监听入口：IHUI-API（8802）、AI-SERVICE（8803）、CLI 本地回调服务器、
worker 健康检查端口。不含测试夹具（`__tests__` / `*.test.ts`）——测试里用
`HOST=0.0.0.0` 或 `listen(0)` 是隔离环境的合法夹具，不构成生产暴露。

## 硬基线

1. **默认回环绑定**。所有对外服务未显式配置时绑 `127.0.0.1`，杜绝源站端口被公网直击。
   - IHUI-API：`apps/api/src/config/index.ts` 的 `HOST` schema 默认 `127.0.0.1`，
     `apps/api/src/index.ts` 运行时 `process.env.HOST ?? '127.0.0.1'`。
   - CLI 回调：`apps/cli/src/lib/sso.ts` 的 `CALLBACK_HOST = '127.0.0.1'`，
     `apps/cli/src/server/http-server.ts` 默认只绑回环，显式传 `host` 才放开。
   - worker：`apps/api/src/worker-entry.ts` 健康检查绑 `127.0.0.1`。
   - 需要跨机访问时必须在 `.env` 显式写 `HOST=0.0.0.0`，不得改默认值。

2. **禁止组合禁令**：**禁止全网卡监听 + 文件内明文密码 + 明文 Basic 组合**。
   三者任一项单独存在时要评审；三项同时出现（OpenCode `0.0.0.0:3084` +
   `service.json` 明文密码 + 明文 HTTP Basic 那种形态）一律判为不可接受，必须整改：
   - 全网卡监听 → 收回回环，或经本机 TLS / 域套接字 + 隧道暴露；
   - 文件内明文密码 → 凭据进 OS keychain / DPAPI（`packages/auth/src/credential-vault.ts`，RP-4 已交付），明文零落盘；
   - 明文 Basic → 入站认证改用带签名的票据 / Bearer token，传输走本机 TLS 或域套接字。

3. **入站认证不得用明文 Basic**。仓内 `Authorization: Basic ...` 命中经核实全部是
   **出站**调用第三方（paypal / ai-vendors / im-gateway / relay proxy），非本服务入站校验，合法。
   新增入站 `req.header('authorization')` 的 Basic 校验会被静态门判红。

4. **传输**。本机服务之间走 `127.0.0.1` 明文 + 隧道（Cloudflare / EO），或本机 TLS / 域套接字；
   禁止把带凭据的服务直接用 `0.0.0.0` 暴露到局域网。

## 与其他门的分工

| 面 | 门 | 判什么 |
|---|---|---|
| 代码/配置静态基线 | `scripts/check-listen-baseline.mjs`（本票） | 默认回环绑定不回退、无生产全网卡硬编码/明文密码/入站 Basic、本清单在位 |
| 部署运行态 | `scripts/security/check-service-baseline.mjs`（第十九件） | nssm 环境变量指纹、启停策略、真机 `0.0.0.0` 且 <49152 端口采集比对 |
| 凭据封装 | `packages/auth/src/credential-vault.ts`（RP-4） | OS keyring/DPAPI + AES-GCM，明文零落盘 |
| 公网路径探测 | `scripts/check-public-path-probe.mjs` | 只读探测公网入口与换流窗口，不改绑定面 |

静态门看不到进程实际绑定，故不宣称"运行时无 0.0.0.0 监听"；运行态结论由部署态门出。

## 评审检查项（新增监听入口时逐条过）

- [ ] 默认是否绑 `127.0.0.1`？显式放开是否有文档理由？
- [ ] 是否引入任何文件内明文密码 / secret 字面量？
- [ ] 是否新增入站明文 Basic 校验？（出站调第三方不算）
- [ ] 凭据是否走 `credential-vault`（keychain/DPAPI）而非裸环境变量 / 配置文件？
- [ ] 传输是否本机 TLS / 域套接字 / 回环 + 隧道？
- [ ] 静态门 `check-listen-baseline.mjs --head` 与部署态门 `check-service-baseline.mjs` 是否都跑过？
