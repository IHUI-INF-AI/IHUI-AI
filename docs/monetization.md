## 二、SaaS 订阅分层(核心收入流)

### 免费版(Free)— 流量入口

**价格**:¥0/月

**功能**:
- 100 条对话/月(共享模型)
- 1 个知识库(100 文档)
- 1 个自定义 Agent
- Web 端 + CLI 端访问
- 社区支持

**目的**:降低试用门槛,获取用户流量,转化为付费用户。

### Pro 版(个人/小团队)— 主力收入

**价格**:¥49/月 或 ¥499/年(省 15%)

**功能**:
- 无限对话(176 模型任选)
- 10 个知识库(每个 1000 文档)
- 20 个自定义 Agent
- 全 8 端访问(Web/API/CLI/Desktop/Extension/Mobile/Miniapp)
- MCP 工具协议
- 工作流编排(5 个/月)
- 邮件支持(24h 响应)

**目标用户**:独立开发者、自媒体、小团队。

**对标**:ChatGPT Plus ¥160/月,IHUI Pro ¥49/月 = 省 70%。

### 团队版(Team)— 高客单价

**价格**:¥199/人/月 或 ¥1999/人/年(5 人起)

**功能**:
- Pro 版全部功能
- 团队协作(共享知识库/Agent)
- 100 个工作流/月
- SSO/OAuth 集成
- 审计日志
- 优先支持(4h 响应)
- 私有模型接入(自部署 Ollama/vLLM)

**目标用户**:中小团队、创业公司、AI 教育机构。

**对标**:ChatGPT Team ¥200/人/月,IHUI Team ¥199/人/月 + 8 端 + 私有部署。

### 企业版(Enterprise)— 大客单价

**价格**:¥2999/月起(含 10 席位),定制报价

**功能**:
- 团队版全部功能
- 不限席位数
- 私有化部署(客户服务器)
- SLA 99.9% 可用性
- 专属客户成功经理
- 定制开发(20 人天/月)
- 培训认证(5 人/年)
- 7×24 电话支持

**目标用户**:中大型企业、政府、教育机构。

**对标**:Notion AI 企业版 ¥800/人/月,IHUI 企业版 ¥300/人/月 + 私有部署 + 定制。

## 十一、技术配置说明

### 套餐限制实现

订阅套餐限制在 `packages/database/src/schema/subscription.ts` 定义,通过中间件 `apps/api/src/plugins/subscription.ts` 强制执行。

### 支付集成

- **Stripe**(海外):`apps/api/src/routes/payment/stripe.ts`
- **微信支付**(国内):`apps/api/src/routes/payment/wechat.ts`(已激活)
- **支付宝**(国内):`apps/api/src/routes/payment/alipay.ts`

### 自动续费

通过 Stripe Subscriptions / 微信支付代扣实现,失败自动重试 3 次。

## 十二、风险与应对

| 风险 | 应对措施 |
| --- | --- |
| 模型 API 成本上涨 | 接入多个 Provider,LiteLLM 自动路由最低成本 |
| 用户增长慢 | 加大内容营销 + SEO + 社区运营 |

| 支付通道风险 | Stripe + 微信 + 支付宝三通道备份 |
| 数据安全合规 | 私有化部署选项 + Apache 2.0 代码可审计 |
