# AI 对话框 · 真机手感复验清单（2026-11-11）

> 适用范围：`apps/web` 的全局 AI 面板（sheet / float / docked 三档 + FAB + 下拉收起 + 吸边 + 滚动保持）。
> 本文是**可勾选执行**的复验表，不是设计说明；设计约定以 `apps/web/src/lib/ai-panel-bucket.ts` 顶部注释为准。

## 1. 档位与形态（T1）

断点真值：**≤639 sheet / 640–1279 float / ≥1280 docked**。

| 勾选 | ID | 步骤 | 通过标准 | 实测/记录 |
|---|---|---|---|---|
| [ ] | T1-1 | 视口 639 打开面板 | 全屏抽屉（`inset-0`），无停靠列 | |

| [ ] | T1-4 | 视口 1280 | 停靠列，宽 = store width（默认 480） | |
| [ ] | T1-5 | 1440 停靠态看 `--ai-panel-occupy` | 等于 `width + 6`（默认 486px） | |

## 2. 手机全屏档：下拉收起（T2）

当前阈值：`max(96, min(180, 视口高 × 15%))`。
折算值：375×667 → **100px**；360×800 → **120px**；393×852 → **128px**；430×932 → **140px**。

| 勾选 | ID | 步骤 | 通过标准 | 实测/记录 |
|---|---|---|---|---|
| [ ] | T2-1 | 标题栏空白处下拉 60px 松手 | 弹回，**不收起** | |
| [ ] | T2-2 | 下拉超过上表阈值松手 | 180ms 内滑出，只剩 FAB | |
| [ ] | T2-3 | 点 FAB 重新打开 | 面板完整复原（不是折叠输入条） | |
| [ ] | T2-4 | 从顶部把手起手下拉 | 与 T2-1 一致（把手不吞手势） | |
| [ ] | T2-5 | 从标题文字起手下拉 | 与 T2-1 一致 | |
| [ ] | T2-6 | 点标题栏按钮 / ⋯菜单 | 正常点击，**不触发**拖拽位移 | |
| [ ] | T2-7 | 消息区上下滑动 | 只滚消息，面板**不位移** | |
| [ ] | T2-8 | 键盘弹出时下拉 | 跟手无两段跳；松手后布局不塌 | |
| [ ] | T2-9 | 下拉一半停住 | 面板同步下移，透明度 ≥ 0.4，内容可读 | |
| [ ] | T2-10 | 快速甩动（位移 ≥ 阈值） | 收起；位移 < 阈值时即使很快也弹回（**当前无速度判定**，属预期） | |
| [ ] | T2-11 | 中低端 Android 连续下拉 10 次 | 无掉帧/卡顿/白屏；不出现 transform 残留 | |
| [ ] | T2-12 | 下拉中途切后台再回 | 面板不留在半位移状态 | |

**注意**：T2-11 若掉帧，先看是否流式输出进行中（流式本身占主线程），再决定是否调参。

### 7.2 现象 → 调参决策

| 现象 | 调整 | 建议值 | 风险提示 |
|---|---|---|---|
| 轻扫就误关 | 阈值下限 96→120；或系数 0.15→0.18 | 120 / 0.18 | 超过 140 会「甩不动」 |
| 要拖很长才关 | 下限 96→80；系数 0.15→0.12 | 80 / 0.12 | 低于 72 误关率明显上升 |
| 跟手掉帧 | 透明度下限 0.4→0.55；分母 0.6→0.8 | 0.55 / 0.8 | 视觉「拖不动」感增强 |
| 甩出/弹回生硬 | 180ms→220ms，缓动 `cubic-bezier(0.32,0.72,0,1)` | 220ms | 超过 260ms 显黏手 |
| 吸边太积极 | 24→16 | 16 | 低于 12 等于没有吸边 |
| 吸不住 | 24→32 | 32 | 不要超过 40（受 48px 退化保护约束） |
| 640–700 太挤 | 浮窗宽 360→340 | 340 | 320 时模型名会截断 |
| 高屏浮窗顶边 | 高度上限改 `min(600, H×0.85)` | 0.85 | 需同步改 `getFloatSize` 与单测 |
| 手机 FAB 挡内容 | 56→52 | 52 | 低于 48 不满足触控目标 |
