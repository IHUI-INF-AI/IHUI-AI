# R109 — 那个负责抓溢出的工具，抓不到溢出

> 12 个容器工具，六个门（R97–R106）、物化器（R107）、渲染+蒙太奇（R108）都跑过了。
> 这轮收最后两个，撞上一个必须记下来的负结果。

## 1. 它说它干什么

`slides_test.py` 的自我描述：

> Check a PPTX for content overflowing the original canvas by **rendering with padding and inspecting the margins**.

听起来正是我缺的那一环——一个自动化的溢出检查。

## 2. 三次探测，同一个答案

| 输入 | 输出 | rc |
|---|---|---|
| 正常 deck | `Test passed. No overflow detected.` | 0 |
| 文字推到右边缘外 | `Test passed. No overflow detected.` | 0 |
| 从 **-4,000,000 EMU** 起、宽 **30,000,000 EMU** | `Test passed. No overflow detected.` | 0 |

第三种：画布只有 12,192,000 EMU 宽，这个形状从负坐标起、比画布宽一倍多。**它说没问题。**

## 3. 我不信它，去看了画面

渲染第二个 deck，读图：

**“OFF” 三个字母贴在右边缘，后半截被画布裁掉了，“CANVAS TEXT” 完全不在。**

**这是溢出，任何眼睛都看得出来。工具说 clean。**

## 4. deck 本身没问题

先排除了输入的责任：

```xml
<p:sldSz cx="12192000" cy="6858000"/>
```

标准 16:9 画布，尺寸声明齐备。**该给的几何信息它都有。**

⇒ **失败在工具，不在输入。**

## 5. 于是这个结论

**`slides_test` 不能当溢出门用。**

它的退出码对"干净"和"溢出"给同一个值 —— **这个退出码不携带任何信息**。

R108 那条路（渲染 + 人眼）**仍然是唯一真正有效的验证**。

这不是"又找到一个工具能用"，而是"**发现了一个以为能用、实际不能用的工具**"。两种结果都值得记，但后者更需要写下来。

## 6. 对照：另一个工具行为正确

同批测的 `ensure_raster_image.py`：

```
ensure_raster_image.py 对一个已经是栅格的 BMP  ->  rc=0，一个文件都没写
```

**这是对的。** BMP 本来就是栅格，无事可做。

⇒ **沉默 = 没有需要做的事**，不是失败。

两个工具放在一起看很有意思：一个该说话时沉默（`ensure_raster_image`，正确地沉默），一个该报警时不报（`slides_test`，错误地沉默）。**都沉默，含义完全相反。**

## 7. 12 个工具的账终于平了

| 轮次 | 覆盖 |
|---|---|
| R97–R106 | 六个门 |
| R107 | 物化器 |
| R108 | render_slides + create_montage |
| **R109** | **slides_test + ensure_raster_image** |

`runtime_helpers.py` 的三层环境变量在 R108 已记。**`container_tools` 目录下 12 个工具，全部有契约记录了。**

## 8. 落成

`apps/ai-service/app/core/codex_presentations_toolkit.py`：

- `TOOLS`（12 条，名字 + KB）+ `TOOL_COUNT=12` + `toolkit_covers_all_tools()`
- `SLIDES_TEST_DESCRIPTION`（逐字）
- `PROBE_CASES`（3 条，**全部返回同一句 pass**）
- `OVERFLOWING_DECK_PASSED=True` / `SLIDES_TEST_DETECTS_OVERFLOW=False`
- `RENDERED_OVERFLOW_OBSERVED=True` / `VISIBLE_OVERFLOW_WITH_CLEAN_VERDICT=True`
- `SLIDE_SIZE_XML`（逐字）→ `DECLARATION_NOT_THE_PROBLEM=True`
- `EXIT_CODE_CARRIES_INFORMATION=False` / `USABLE_AS_OVERFLOW_GATE=False`
- `ENSURE_RASTER_*` + `SILENCE_MEANS_NOTHING_TO_DO=True`

**12 passed**、ruff 全绿、水印 2/2。

两条反向变异：`SLIDES_TEST_DETECTS_OVERFLOW` 改 True → 红；`TOOLS` 砍掉一个 → 红。

## 9. 诚实边界

1. **我只试了 3 种溢出形态**。有可能存在某种它能抓住的形态，我没造出来。
2. **它到底检测什么，我没定位**——只知道在我造的这些上它不报。
3. `--pad_px` 我试了默认和 200，**更大值没试**。
4. 我没读它的实现（那是对方源码，读可以但不该照抄）。
5. `ensure_raster_image` 只测了 BMP 一种输入，**非栅格格式（SVG/EMF）能否真转，没验证**。
