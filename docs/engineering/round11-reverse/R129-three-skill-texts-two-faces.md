## 二、两份表格：一套学说，两个执行面

`spreadsheets` 用 `@oai/artifact-tool` 写本地 xlsx；`excel-live-control` 驱动**已经开着的** Excel 会话。
路由是单向的：

- 请求没点名桌面应用或插件 ⇒ 归 artifact 面
- 一旦进 live 面 ⇒ **粘住**，直到用户显式切换

live 正文明确**禁止**在 live 面加载姊妹 artifact 正文，也**禁止**用 Computer Use 改单元格
（Computer Use 只做 setup 与 focus）。

两份长度接近，是因为 live 有一半是共享工作簿学说的**逐字重复**。

## 三、live 是七道 setup gate 的状态机

| # | 门 |
|---|---|
| 1 | Excel 已开 |
| 2 | 目标工作簿唯一 |
| 3 | 插件已装 |
| 4 | 面板已开 |
| 5 | 已登录 |
| 6 | connected-document 工具可用 |
| 7 | 工作簿已注册 |

铁律是**后一道门不能证明前一道门通过**。三条具体陷阱原文写死：

- ribbon 按钮**不**等于面板已开
- 面板标题**不**等于已登录
- `list_document_sessions` 缺失说明该 thread 没加载工具面，**不是**工作簿注册失败
- `executor_session_id` 永不复用，标题相似也不行

`run_officejs` 是独立闸：调用前必须**当轮**读完 `officejs.md`（8,866 B）。

## 四、算术纪律

优先 `COUNTIFS` / `SUMIFS` / `AVERAGEIFS`——**单条件也用**，因为加第二条件时不用重写。

**禁**：`LET`、数组溢出、`MAP`、`REDUCE`、`LAMBDA`。用熟悉的公式加标注的中间步。

缺失与零必须分开：

- 真零用 `0`
- 缺失/不适用用 `"n.a."`
- **禁** `IFERROR(...,0)` 一把盖掉——那会把坏引用变成健康的零
- `ISNUMBER` 守卫不得把失败的前置条件变成健康的零
- `PRODUCT` 会**静默跳过空格**，所以必填因子要先校验

格式码必须 Excel-invariant，禁按 locale 换分隔符。

## 五、Checks/Audit 是终端

外部任何地方（假设页 / 构建页 / 摘要 / 输出闸）都不得消费 Checks 的结果。它可以读别人，不许被读。

## 六、presentations 大半是写作质量引擎

五类劣质措辞：awkward / flowery / vague / unnecessary / illogical。
七类 AI-ism：标点、`it is not X`、被动、祈使式标题、口号、三段式、连字符复合词。

标点禁令在原文是绝对句：em dash / semicolon / ASCII dot / vertical bar / arrow，
**每一条都写作 always slop**。

**程序化绘图整体禁止**：不许 Python 画，不许程序化矢量。只能用 image search 或 imagegen；
除非当背景，否则同一张图不得重复使用。例外极窄：必需的表格、数据图表、显式要求的可编辑图示
保持原生对象，且该例外**不得**用来造装饰面板。

字号是数字不是形容词：无模板时 deck 标题 ≥42pt、slide 标题 ≥32pt、正文 ≥17pt。
溢出先**砍内容**再缩字。

## 七、修的两处真缺陷

1. `#NAME?` 拆分把正则转义符带进了 token。改成 9 个词面 token 作真相源、pattern 从它派生，
   并断言 pattern 等于源串。
2. Office.js 那条自检方向写反：`run_officejs` 本就**该在默认集合之外**。
3. 另修一个恒真误判：`BLANK_OVERRIDE_MEANS_BASE == ZERO_OVERRIDE_MEANS_ZERO` 两者都是 True
   但语义不同（"空覆盖=用基线" vs "零覆盖=用零"），改为"两者都必须成立"。
