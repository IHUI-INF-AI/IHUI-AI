# R54 — 原生二进制轻量交叉引用取证工具沉淀

- 日期：2026-11-18
- 本轮性质：**工具沉淀**（把 R52/R53 两轮实战提炼的方法固化为仓库可复用脚本，零源码改动）
- 产物：`scripts/evidence/native-xref-probe.py`（纯标准库，无 pefile 依赖）

---

## 1. 为何沉淀（杠杆判断）

R52/R53 连续两轮都卡在同一个瓶颈：382MB 原生 PE（codex.exe）做单符号取证。

| 路径 | 成本 | 结果 |
|---|---|---|
| Ghidra headless 全量 auto-analysis | 1200s 超时 + `.` 路径拒绝 | R52 失败 |
| R53 scratch 版脚本（一次性） | 秒级 | 成功但宿主回收，无法复用 |

R53 的方法本身是整条 goal 的**能力倍增器**——它把未来每一轮单符号取证从「分钟级超时」
降到「秒级」，但不沉淀就等于这个突破只用了这一次。故本轮把方法固化为仓库脚本。

---

## 2. 方法（四步，见 R53 §1）

1. **解析 PE 段表**（纯手算 DOS→PE→optional→section table，无 pefile）：建立各段
   VA ↔ fileoff 映射；
2. **定位目标串 fileoff**：`bytes.find` 循环取全部出现，换算 VA（默认落 `.rdata`）；
3. **扫 `.text` 内 RIP-relative LEA**：`48/4C 8D` + modrm `mod=00 rm=101` = disp32，
   算每条引用目标 VA 比对目标串 VA；
4. **定向反汇编语境**（可选 `--disasm`）：对每个命中点 objdump 看 ±window 语境
   （序列化块 / 分支 / 表驱动）。

用法：

```bash
python scripts/evidence/native-xref-probe.py <binary> \
    --string active_turn_not_steerable --string thread_rollback_failed [--disasm] [--json]
```

输出：每组字符串的 VA、引用它的 LEA 指令 VA、**成对距离**（辅助判「同码表相邻」vs
「分散控制流」）、`--json` 结构化结果。`--disasm` 附反汇编语境。

---

## 3. 实测（与 R53 对照 + 增强）

对 codex.exe 取证 steer/回滚两串，沉淀脚本跑通且**比 R53 更完整**：

- R53 字符串上限截到前 3 处 ⇒ 3 对 LEA（delta 243/243/254）；
- 本脚本取全量 ⇒ **6 对 LEA，delta 全部成对同区（154–416）**，把「同码表相邻」结论
  从 3 例扩到 6 例确证。

成对距离（前 3 对与 R53 一致，后 3 对为全量新增）：

## 4. 本轮纠偏（沉淀时的实战 bug）

首版 `find_string_fileoffs` 加了「前一字节须非标识符」的 token 边界过滤（想避免命中
更长串的子串）。实测返回 `[]` 零命中——错误码表常把变体**连体存储**（如
`...mptsactive_turn_not_steerablethread_rollback_failed...`），目标串前一字节正是别的
token 尾字符，被全滤掉。

**修正**：偏移采集层取全部出现、不做边界过滤；语境甄别交给调用方（结合反汇编 +
成对距离）。教训入档：取证工具的采集层不要猜语境，猜错会静默丢证据。

## 5. 验证

- `py_compile` OK；`ruff check` 全绿；水印 1/1；
- codex.exe 实跑：12 条 LEA 命中、成对距离 6 对全出、`--json` 结构化输出正常；
- 扫描逻辑单点复核：已知 R53 命中点 `0x141AB6039` 字节 `488d156e1de90f` 反解 target
  = `0x151947DAE` 完全吻合。

---

## 6. 纪律与边界

- 本工具只**取证**、不改动二进制；
- **结论须结合反汇编语境判定，不得仅凭「字符串相邻」冒充因果**（R52 教训，已写进
  模块 docstring）；
- 零第三方依赖（标准库 mmap/struct/argparse），符合仓库「脚本零依赖」约定；
- 未配 PDB / 函数名已 strip 时，`--disasm` 的 `call` 目标语义是据参数形态推定，非
  符号确证——反汇编输出供人工判定，工具不自动下因果结论。
