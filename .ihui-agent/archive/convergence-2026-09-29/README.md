# 2026-09-29 交付收敛这一轮的取证脚本(受版本控制的唯一副本)

为什么把这些脚本入库:那几枚旁路提交的正文把 `.ihui-agent/tmp/o81-resume/…` 当替代证路径引用,
而该目录被 `.gitignore` 忽略 ⇒ 换机或他人接手时这些指针一律不可兑现。台账 §1 第 3 条与
"文档不得写跑不通的出路"是同一条禁令,所以把**判据的载体**搬到受版本控制的位置,
而不是把提交历史重写一遍(已入库且是他人提交的祖先,重写禁止)。

刻意不入库的东西:当次的读数与日志。本仓口径是"数字一律现跑现读",
把某次的条数冻进仓里只会变成第二本会腐烂的账(参见"别把移动量钉成健康期望")。

各件的作用(都不是判据本体,是**复现某次判定**的出口):

- `build-mine2.mjs` / `build-mine4.mjs` / `build-mine5.mjs` — 台账让号器:键位命中唯一 / 标题逐字不变 /
  注记只落行尾(插在编号位会改掉复合主键)/ 指针行连带改指 / 零损失按位置逐字 / 旧行原文进已入库归档件。
  `mine5` 是参数化版(编号走 argv、跳距走 env `GAP`),并**纠正了让号有效性判据**:拒的条件是
  "对侧仍逐字带着这一行",不是"旧号在不在 merge-base"(union 的 `own + max(0, 对侧 − max(基底, own))`
  在两侧都 0 份时不会把基底那份补回来)。
- `build-band.mjs` — 一次性把整批让过的号挪出并发取号前沿(跳距写死会腐烂,故走 env)。
- `patch-fold.mjs` — 给 `union-converge.mjs` 补"对侧就地改写、本侧未动 ⇒ 不带旧行"这条对称规则的补丁器。
- `patch-sim.mjs` — 给折叠判据补**身份闸**(同号两件事 ≠ 同一件事被改写):复用
  `scripts/lib/live-doc-similarity.mjs` 的字符二元组 Jaccard 与 `SIM_THRESHOLD`,不写第二把尺子。
- `append-ticket.mjs` — 台账追加票(底稿取 HEAD、行数净增 1、原行逐字不动、取号含远端面)。
- `ab-fold2.mjs` / `probe-loss.mjs` — 把"红是不是我造成的"变成可判:同一三面输入下
  分别与"中和本票判据"的口径对比重数,并让落地闸的两把尺子(期望表 / 少带桶)在同一次调用里对账。
- `headcheck.sh` — 绿必须在被审那份上:把 blob 覆盖进 `git archive HEAD` 的隔离检出,再跑 self-test/镜像 +
  纯净 HEAD 基线对照 + 变异自证(物化后逐件比 `hash-object`,空变量重定向会先清空文件)。

共同套路:一律 `git show HEAD:<path>` 取底稿 → 锚点断言"命中恰好 1 次" → 临时件 → `node --check` →
`git hash-object -w` → 由 `scripts/object-space-land.mjs`(`LAND_BLOBS` + `LAND_BLOB_PROOF`)落地;
**从不写工作树** —— 本机这些文件的磁盘副本常年含他人未入库的实现。
