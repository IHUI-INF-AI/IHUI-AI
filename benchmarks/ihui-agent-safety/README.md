# IHUI Agent Safety Benchmark

一个**确定性、无外网、无数据库**的本地 benchmark。第三方克隆仓库后，用同一条命令即可复算报告里的每个结论。

## 跑法

```powershell
node benchmarks/ihui-agent-safety/run.mjs
# 指定输出
node benchmarks/ihui-agent-safety/run.mjs --out docs/benchmark-evidence/2026-11/l16-benchmark-run-2026-11-26.json
```

通过标准：6 项全部 `ok=true`，进程 exit 0。

## 六项尺子

| #   | 检查                        | 判据                                                                               |
| --- | --------------------------- | ---------------------------------------------------------------------------------- |
| 1   | `desktop-invoke-registry`   | `无对应命令=0`、`重名=0`、`清单差异=0`                                             |
| 2   | `window-security`           | `红=0`                                                                             |
| 3   | `mcp-loopback-route-parity` | Fastify 源与 Host 适配器 15=15、missing/extra/duplicate 均为 0                     |
| 4   | `acp-three-end-contract`    | files=9、missing=0、problems=0、ends=3                                             |
| 5   | `acp-method-single-source`  | `state=ok`、`越界=0`                                                               |
| 6   | `r8-real-window`            | 两份证据 JSON 均 `ok=true`、`authMode=real-login`、420→48→420→420、`heightDelta=0` |

## 不声称什么

- 不是第三方认证，也不含竞品排名。
- 不覆盖数据库、外网服务与真实用户流量。
- R8 读数直接读证据 JSON，不用单测冒充真机；证据文件本身由 `r8_selftest.rs` 在真实 Tauri 窗口产出。

## 输出

`docs/benchmark-evidence/2026-11/l16-benchmark-run-2026-11-26.json`：

- `schema`, `generatedAt`, `gitHead`
- `scope`, `nonClaims`
- `summary`：`total/passed/failed/score`
- `checks[]`：每项的 `id/title/ok/exitCode/stdout/stderr/durationMs`，MCP/ACP 还带结构化 `report`

报告是给外部复核者看的“可复现事实包”，不是营销分数。
