# 五层能力体检

一条命令把"能验证的层"跑成读数，不能验证的层如实标 `unjudged`。

```bash
node benchmarks/capability-scorecard/run.mjs
```

| 层         | 检查                                 | 判据来源                                                                                                                                                                                                                                                                                                                                                                      |
| ---------- | ------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 记忆       | `memory.restart-zero-reembed`        | 重启后 chunk 向量来自磁盘、只 embed query；换模型/坏文件/TTL 都判红                                                                                                                                                                                                                                                                                                           |
| 规划与反思 | `agent.baseline-9cases`              | 工具配对、压缩、续跑、错误恢复四类行为的录制回放基线                                                                                                                                                                                                                                                                                                                          |
| 工具执行   | `sandbox.low-integrity-real-process` | 低完整性进程真启动、stdout 可读、AppContainer 令牌真阻断网络、写中完整性路径被拒、Job 终止整树                                                                                                                                                                                                                                                                                |
| 工具执行   | `toolhost.process-separation-rpc`    | 独立 tool-host 子进程 + 命名管道 + token 握手 + 双键幂等重放 + AppContainer/继承档写盘边界 + AppContainer 网络阻断 + 多客户端池 + 跨宿主双键去重 + Manager 重启 + MCP raw relay + 程序路径/参数/超时/cwd/env/编码收口 + 安装根目录布局 + 超时收口                                                                                                                             |
| 工具执行   | `toolhost.desktop-git-business`      | 桌面正常业务 git 通道（`git_workspace_status`）经 tool-host `inherit` 档执行 `git status`，临时仓库返回 facts                                                                                                                                                                                                                                                                 |
| 工具执行   | `toolhost.cli-foreground-dual-key`   | CLI `run_command` 消费方：同 `turnId\|toolCallId` 重试只执行一次、`ToolContext` 双键命中宿主缓存、`IHUI_TOOL_HOST_FOREGROUND=1` 时前台命令真走宿主、默认 AppContainer 档 ping 断网、`TaskPrepare` Git/非 Git 副本写入→diff→publish 回源（含源改动拒绝覆盖）、假模型 `runAgent` 经 `FileWrite` 写副本、任务副本里的 `run_command` 默认走宿主 AppContainer 并写副本后再 publish |
| 工具执行   | `toolhost.mcp-client-relay`          | MCP stdio 客户端经宿主 loopback relay 完成 initialize/tools/list/tools/call；`isError` 只失败结果不标死连接                                                                                                                                                                                                                                                                   |
| 推理大脑   | 未判定                               | 没有模型质量评测；要真分数必须外部模型 key，拒绝拿路由单测冒充                                                                                                                                                                                                                                                                                                                |
| 感知       | 未判定                               | 截图/OCR/浏览器链路需要真实桌面会话，不在无人值守环境伪造通过                                                                                                                                                                                                                                                                                                                 |

当前最终读数：**111 通过 / 0 失败**（记忆 37、规划与反思 9、沙箱 45、toolhost 20）。toolhost 20 = 进程集成 7 + 桌面 git 1 + CLI 双键/AppContainer/Git+非 Git TaskPrepare/任务命令默认宿主化/会话级文件工具写副本 10 + CLI MCP relay 2。推理大脑、感知、外部榜仍按 `unjudged` / `not_run` 记录，没有新分数。

外部榜（SWE-bench Verified / Terminal-Bench / GAIA）在本文件里固定为 `not_run`：
需要数据集 + 可用模型凭据，本机未配置。**没有跑过就不写分数**，这是这张表唯一的规矩。

产物：`benchmarks/capability-scorecard/results/scorecard.json`（不入库）。
