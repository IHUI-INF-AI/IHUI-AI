workspace 中的 lib.mjs 里 omit(obj, keys) 应返回删除指定键后的浅拷贝,且不得修改原对象。当前实现有两个 bug:过滤条件写反(留下了该删除的键)且直接在原对象上 delete。请修复,要求:

- omit({a:1,b:2,c:3}, ['b']) 深度等于 {a:1, c:3}
- omit({a:1}, ['zz']) 深度等于 {a:1}(不存在的键安全)
- 调用后原对象保持 {a:1,b:2,c:3} 不变(不得原地修改)
