## 项目简介(Abstract 风格)

IHUI AI(智汇 AI)是一个一站式全栈 AI 操作系统,基于 TypeScript Monorepo 架构,集成 AI Agent 编排、知识库 RAG、多模型统一调度、工作流可视化、跨端同源分发等完整能力。该项目采用 Apache 2.0 开源协议,代码完全可审计,支持企业私有化部署,适合学术研究、政企应用、教育培训等多种场景。

## 智谱 GLM 系列完整支持

### 支持的 GLM 模型

**对话模型**:
- GLM-4(智谱 4 代旗舰)
- GLM-4-Plus(超长上下文 1M)
- GLM-4-Air(轻量)
- GLM-4-Flash(超快)
- GLM-3-Turbo(上一代,仍可用)
- ChatGLM-6B(开源 6B)
- ChatGLM2-6B(开源 6B 升级)
- ChatGLM3-6B(开源 6B 升级)
- GLM-4-9B(开源 9B)
- GLM-4-32B(开源 32B)
- GLM-4-130B(开源 130B)

**多模态模型**:
- GLM-4V(视觉)
- GLM-4V-Plus(视觉旗舰)
- CogVLM(开源视觉)
- CogAgent(开源 GUI Agent)
- GLM-4-Voice(语音)

**嵌入模型**:
- Embedding-2(中文嵌入)
- Embedding-3(升级版)
- bge-large-zh-v1.5(IHUI AI 内置备选)

## GLM-4-Plus 超长上下文应用

IHUI AI 针对 GLM-4-Plus 的 1M token 上下文做了专门优化:

### 应用 1:全本小说分析
```typescript
// 加载百万字小说
const novel = await loadDocument('novel.txt')  // 2MB
const agent = createAgent({
  model: 'glm-4-plus',
  context: novel,
})
const result = await agent.run('分析主角成长弧光,给出关键转折点')
```

### 应用 2:法律卷宗审查
```typescript
const caseFiles = await loadMultipleDocuments([
  '起诉状.pdf',
  '答辩状.pdf',
  '证据材料.pdf',
  '庭审笔录.pdf',
  '判决书.pdf',
])
const agent = createAgent({
  model: 'glm-4-plus',
  context: caseFiles,
})
const review = await agent.run('审查所有法律风险点,出具审查意见')
```

### 应用 3:学术综述生成
```typescript
const papers = await searchArxiv('RAG optimization', limit: 50)
const agent = createAgent({
  model: 'glm-4-plus',
  context: papers,
})
const survey = await agent.run('生成 5000 字研究综述,包含方法对比和未来方向')
```
