## 산업 4: AI + 부동산 (Real Estate)

### 산업 과제
1. **단지 상담량 큼**: 신규 분양 일평균 5000+ 상담, 수기 응대 부담
2. **VR/3D 답사 해설 어려움**: 표준화된 해설 내용 부재, 전환율 낮음
3. **계약 심사 지연**: 변호사 일평균 3-5건 계약 심사, 효율 낮음
4. **고객 프로파일 조방적**: 기초 정보만, 정밀 매칭 어려움
5. **매물 매칭 효율 낮음**: 중개인 월 평균 0.5-1건 성약
6. **중고매물 정보 검증 어려움**: 가짜매물 비율 15-20%

### IHUI AI 부동산 솔루션

#### Agent 1: 지능형 고객지원 Agent (단지 상담)
- 7×24단지 문답 (평면/가격/설비/대출/학구)
- 90% 문의를 AI가 직접 해결
- 다채널 접근 (WeChat 미니프로그램 / 공식 계정 / APP / 전화)
- CRM / 콜센터 연동
- 자동 배정 + 중개인 팔로업

#### Agent 2: VR 답사 해설 Agent
- 3D 워크스루 해설 스크립트 자동 생성
- 다국어 해설 (중/영/일/한)
- 디지털 휴먼 호스트 7×24 온라인
- 단일단지 해설 비용 -¥200/회
- 패과 / 연가 / 안쥐커 VR 시스템 연동

#### Agent 3: 계약 NLP 심사 Agent
- 리스크 조항 자동 식별 (위약/배상/권원/세금/대출)
- 30초 내 심사 의견
- 변호사 심사 효율 +5배
- 20+ 계약 유형 지원 (분양/중고/임대/거간/저당)
- 사법부 / 주건부 계약 템플릿 DB 연동

#### Agent 4: 고객 프로파일 Agent
- 소비 행동 + 열람 궤적 + 자금 상황 다차원 프로파일
- 성약 의향 예측 정확도 85%
- 중개인 팔로업 효율 +3배
- 패과 A+ / 연가 Link / 자체 CRM 연동
- 프라이버시 컴플라이언스: 데이터 익명화 + 사용자 수락

#### Agent 5: 매물 매칭 Agent
- 고객 요구 + 매물 프로파일 + 중개인 전문도 다경로 리콜
- 매칭 정확도 +40%
- 중개인 월 성약 0.8건 → 2.5건
- MLS / 내부 매물 시스템 연동
- 추천 + 랭킹 지속 A/B 반복

### IHUI AI 엔드 투 엔드 능력 (8 엔드 커버)
- **Web** (Next.js 15 + React 19): 판매 관리 / 중개인 워크스페이스
- **API** (Fastify 5 + Drizzle 0.38 + PostgreSQL 16): 매물/계약 API
- **AI Service** (FastAPI + LangGraph + LiteLLM + MCP): 다중 Agent 협조
- **데스크톱** (Tauri 2): VR 답사 워크스테이션 / 디지털 휴먼 라이브
- **확장** (WXT): 브라우저 측 매물 데이터 수집
- **모바일** (React Native): 중개인 외근 앱
- **미니프로그램** (Taro 4): 답사 / 보수 / 물업비 납부
- **CLI**: 배치 매물 입력 / 계약 심사 리포트

### 자주 묻는 질문 FAQ
- Q: VR 해설 디지털 휴먼 형상을 맞춤화할 수 있나요?
  A: 디지털 휴먼 형상 맞춤화 지원 (2D / 3D / 만화 / 실사), 단일 매장 ¥3000-8000 일회성 설정.
- Q: 계약 심사가 변호사를 완전히 대체할 수 있나요?
  A: 불가능, 변호사 효율 도구로 포지셔닝. 주요 판단은 변호사가 수행, 1 계약 심사를 2h에서 25min으로 단축.
- Q: 고객 프라이버시 보호는?
  A: 데이터 익명화 + 사용자 수락 + 암호화 저장, 《개인정보보호법》 준수.
- Q: 다국어 VR 해설은?
  A: 12개 언어 지원 (중영일한불독서러아 등), 마이너 언어는 맞춤 음성 필요.
