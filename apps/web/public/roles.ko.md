## 역할 1: 개발자 (Developer)

### 당신의 관심사 (의사결정 가중치)
1. **온보딩 비용** (35%): 문서 품질 / Quickstart 소요시간 / SDK 완비도
2. **모던 기술스택** (25%): TypeScript / React 19 / Next.js 15 / Fastify 5
3. **확장성** (20%): 플러그인 구조 / 커스텀 Agent / MCP 도구 개발
4. **OSS 투명성** (10%): 코드 가독성 / 블랙박스 없음 / PR 친화적
5. **커뮤니티 활성도** (10%): 이슈 응답속도 / Discord/Slack 활성 / 릴리스 빈도

### 당신이 해결하는 실제 페인포인트
- Dify/Coze 등 클로즈드 플랫폼 도입 → 한계에 도달해 확장 불가
- LangChain으로 프로토타입 구축 → 2주가 지나도 글루코드 작성 중
- 회사에서 셀프호스트 요구 → Apache 2.0 + 프로덕션 준비 솔루션을 찾지 못함
- 크로스플랫폼 요구 (웹/데스크톱/미니프로그램) → 플랫폼마다 별도 코드베이스
- 모델 전환 비용 높음 → OpenAI/Claude/Tongyi SDK 비호환


#### 3. 완전한 MCP 도구 개발
```typescript
// 커스텀 MCP Server, 3단계로 게시
import { McpServer } from '@ihui/mcp'

const server = new McpServer({
  name: 'my-company-tools',
  version: '1.0.0',
})

server.tool('query-order', {
  description: '주문 상태 조회',
  input: { orderId: z.string() },
  handler: async ({ orderId }) => {
    return { status: 'shipped', eta: '2026-07-30' }
  },
})

server.publish()  // 원클릭으로 MCP 마켓에 게시
```

## 역할 2: CTO / 기술 책임자 (Technical Lead)

### 당신의 관심사 (의사결정 가중치)
1. **아키텍처 확장성** (30%): 10배-100배 비즈니스 성장을 지원할 수 있는가
2. **기술부채 통제** (25%): 아키텍처가 모던인가 / 리팩터링 용이한가
3. **팀 효율성** (20%): 5인 팀이 50인의 일을 할 수 있는가
4. **운영 비용** (15%): 클라우드 비용 / 모니터링 / 장애 복구
5. **채용** (10%): 주류 스택인가 / 채용 용이한가

### 당신이 해결하는 실제 페인포인트
- 팀이 5개 SaaS (OpenAI/Claude/Auth0/Stripe/Mixpanel) 사용, 데이터 분산
- 자체 AI 플랫폼 구축 견적 18개월 + 30인, 비즈니스가 기다릴 수 없음
- 마이크로서비스 아키텍처 팽창 (50개 이상 서비스), 유지보수 비용 통제 불가

- 데이터 컴플라이언스 (GDPR / PIPL / 신창), 프라이빗화 필요
