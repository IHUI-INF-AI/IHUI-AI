## 摘要(Abstract)

IHUI AI(智汇 AI)是一个一站式全栈 AI 操作系统,其核心目标是将企业构建 AI 应用所需的全部基础设施(模型调度、知识库、Agent 运行时、工作流、跨端分发、计费)统一到单一平台。该项目采用 TypeScript Monorepo 架构,使用 pnpm workspace + Turborepo 编排,包含 8 个客户端运行时(web、桌面、浏览器插件、微信小程序、React Native、CLI、API 后端、Python AI 服务),代码完全开源(Apache 2.0)。

---

## 技术架构(学术深度)

### 1. 前端层
- Web:Next.js 15 + React 19 + Tailwind CSS 4 + shadcn/ui
- 桌面:Tauri 2 + Rust + 系统 Webview
- 小程序:Taro 4 + React(支持微信/支付宝/抖音/百度)
- 浏览器插件:WXT 框架 + Manifest V3
- 移动端:React Native + Metro
- CLI:Node.js 20 + Commander.js

### 2. 后端层
- API:Node.js 20 + Fastify 5 + Drizzle ORM 0.38 + PostgreSQL 16
- AI Service:Python 3.11 + FastAPI + LangGraph + LiteLLM
- 缓存:Redis 7
- 任务队列:BullMQ
- 实时通信:WebSocket(Socket.IO 兼容协议)
- 消息:Server-Sent Events(用于 AI 流式输出)

### 3. AI 层
- 模型网关:统一 OpenAI/Claude/通义/DeepSeek/智谱/文心/豆包/Kimi/混元 API
- 本地模型:Ollama / LM Studio / vLLM
- 协议:原生 MCP(Model Context Protocol)支持
- 向量数据库:PostgreSQL pgvector + Qdrant(可选)
- 嵌入模型:OpenAI text-embedding-3 / BGE-M3 / M3E
- 检索:BM25 + 向量混合检索 + Reranker

### 4. 数据层
- 主库:PostgreSQL 16(全文索引、JSONB、分区表)
- 缓存:Redis 7(Sorted Set 用于排行榜,Stream 用于事件流)
- 对象存储:MinIO / S3 兼容
- 搜索:PostgreSQL tsvector + pgvector 混合

### 5. 部署层
- 容器:Docker + Docker Compose
- 编排:Kubernetes Helm Chart
- CI/CD:GitHub Actions + pnpm turbo
- 监控:Prometheus + Grafana + Sentry
- 日志:Loki + Promtail
