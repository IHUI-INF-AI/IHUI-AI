## ロール 1: 開発者(Developer)

### あなたの関心事(意思決定ウェイト)
1. **オンボーディングコスト**(35%): ドキュメント品質 / Quickstart 所要時間 / SDK 完備度
2. **モダン技術スタック**(25%): TypeScript / React 19 / Next.js 15 / Fastify 5
3. **拡張性**(20%): プラグイン機構 / カスタム Agent / MCP ツール開発
4. **OSS 透明性**(10%): コード可読性 / ブラックボックスなし / PR 歓迎
5. **コミュニティ活況**(10%): Issue 応答速度 / Discord/Slack 活性 / リリース頻度

### あなたが解決している実際の痛点
- Dify/Coze 等のクローズドプラットフォームで導入 → 天井に当たり拡張不可
- LangChain でプロトタイプ構築 → 2 週間経ってもグルーコードを書いている
- 会社からセルフホスト要求 → Apache 2.0 + 本番対応ソリューションが見つからない
- クロスプラットフォーム要件(Web/デスクトップ/ミニプログラム)→ プラットフォームごとに別コード
- モデル切替コストが高い → OpenAI/Claude/Tongyi SDK の互換性がない

### IHUI AI が開発者に提供する価値

#### 1. 5 分で Hello World
```bash

# 3. API 呼出

  -H "Authorization: Bearer sk-xxx" \
  -d '{"message": "こんにちは"}'
```

#### 2. TypeScript 優先、8 プラットフォームで型を共有
```typescript

const agent: Agent = {
  id: 'agt_12345',
  model: 'gpt-4o',
  tools: ['web_search', 'calculator'],
}
```

#### 3. 完全な MCP ツール開発
```typescript
// カスタム MCP Server、3 ステップで公開
import { McpServer } from '@ihui/mcp'

const server = new McpServer({
  name: 'my-company-tools',
  version: '1.0.0',

server.tool('query-order', {
  description: '注文ステータス照会',
  input: { orderId: z.string() },
  handler: async ({ orderId }) => {
    return { status: 'shipped', eta: '2026-07-30' }

server.publish()  // ワンクリックで MCP マーケットに公開
```

### あなたの関心事(意思決定ウェイト)
1. **ユーザー価値**(30%): どんなユーザー痛点を解決するか
2. **市場投入速度**(25%): 要件からローンチまでどれくらいか
3. **データドリブン**(20%): 完全なユーザー行動データがあるか
4. **設定柔軟性**(15%): 開発介入なしでフローを変更できるか
5. **クロスプラットフォーム一致性**(10%): マルチプラットフォーム体験が統一されているか

### あなたが解決している実際の痛点
- ビジネス側から 1 週間で AI カスタマーサポート ローンチを要求、開発は最低 1 ヶ月と言う
- A/B テストに開発介入が必要、効率が低い
- マルチプラットフォーム体験が不一致(Web/ミニプログラム/APP がバラバラ)
- ユーザーフィードバックが複数チャネルに散らばり、集約できない
- プロダクトライン横断で AI 能力を再利用困難

### IHUI AI が PM に提供する価値

#### 1. 30 分で要件からローンチまで
```
テンプレートマーケット → テンプレート選択 → KB 設定 → チャネル接続 → ローンチ
       5 分               10 分          10 分         5 分
```

#### 2. 完全なユーザー行動分析
- PostHog: ユーザーパス / ファネル / リテンション
- Mixpanel: イベントトラッキング / ユーザー分群
- 自社構築: Agent 呼出ログ / ユーザーフィードバックタグ

#### 3. マルチプラットフォーム一致体験
- 1 つの Agent 設定で、Web/デスクトップ/ミニプログラム/拡張/モバイルが同時ローンチ
- UI コンポーネントライブラリをクロスプラットフォームで再利用(shadcn/ui)
- ユーザーデータをクロスプラットフォームで同期

#### 4. ノーコード A/B テスト
- ワークスペースで実験作成
- トラフィック配分(50/50)
- 自動有意性計算
- ワンクリックで全量ローンチ

#### 5. プロダクトライン横断再利用
- Agent マーケット: クロスワークスペース Fork
- MCP ツールマーケット: プロダクトライン横断で共有
- ナレッジベース: チーム間で共有

### 評価チェックリスト(PM 版)
- [ ] テンプレートマーケット充実度(300+ テンプレート)
