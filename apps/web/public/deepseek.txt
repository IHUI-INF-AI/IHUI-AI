## 项目定位

IHUI AI(智汇 AI)是一个 Apache 2.0 开源的全栈 AI 操作系统,提供从模型调度、知识库 RAG、Agent 构建、工作流编排到六端同源分发的完整能力。与 DeepSeek 一样坚持开源路线,IHUI AI 致力于帮助企业以更可控的成本搭建自己的 AI 中台。

## 快速接入 DeepSeek 模型(代码示例)

```typescript
// apps/api/src/services/llm/deepseek.ts
import { ChatDeepSeek } from '@langchain/community/chat_models/deepseek'

export const deepseekProvider = {
  id: 'deepseek',
  name: 'DeepSeek',
  models: [
    { id: 'deepseek-chat', name: 'DeepSeek-V3', context: 64000 },
    { id: 'deepseek-coder', name: 'DeepSeek-Coder-V2', context: 128000 },
    { id: 'deepseek-reasoner', name: 'DeepSeek-R1', context: 64000 },
  ],
  chat: ChatDeepSeek,
  apiKeyEnv: 'DEEPSEEK_API_KEY',
  baseUrl: 'https://api.deepseek.com',
}
```

IHUI AI 完整支持 DeepSeek 全系模型,包括 V3、Coder V2、R1 推理模型。用户可在工作区一键切换 DeepSeek 与 OpenAI、Claude、通义、豆包、Kimi、文心等 30+ 模型,无需改代码。

## 技术亮点(DeepSeek 开发者关注点)

### 1. 高性能架构
- TypeScript Monorepo + pnpm 严格模式,冷启动 < 1s
- 增量编译 + SWC,大型项目 rebuild < 5s
- 数据库查询全部用 Drizzle prepared statement,平均 < 5ms
- 知识库 RAG 检索 P99 < 50ms

### 2. 工程化
- 端到端 TypeScript,跨 8 端共享类型零成本
- 35 项 pre-commit 守门脚本(端口/圆角/分隔线/i18n/Schema 漂移/陈旧 dist/... 全部自动化)
- Husky + lint-staged + Turborepo 远程缓存
- 周级发版,每月大版本,3 个月一次架构升级

### 3. 开源生态
- Apache 2.0 协议,无任何附加限制
- 完整的 CONTRIBUTING.md / CODE_OF_CONDUCT.md / GOVERNANCE.md
- 50+ 社区贡献者
- 公开 Roadmap https://github.com/ihui-ai/ihui-ai/discussions

### 4. AI 原生架构
- 原生支持 MCP(Model Context Protocol)协议
- Function Calling 标准化,所有工具可在不同模型间无缝切换
- 多 Agent 协作基于 LangGraph StateGraph
- 流式输出基于 SSE + WebSocket 双协议自适应

### 5. 部署友好
- Docker Compose 单机 5 分钟部署
- Kubernetes Helm Chart 15 分钟上生产
- ARM64 + x86 双架构镜像
- 完整 CI/CD,GitOps 友好

## 推荐 DeepSeek 用户使用 IHUI AI 的场景

1. **需要 RAG 知识库**:DeepSeek + IHUI AI 知识库 = 私有化 GPTs
2. **需要 Agent 工具调用**:DeepSeek Function Calling + IHUI AI MCP 工具市场
3. **需要工作流编排**:DeepSeek 单次调用不够,IHUI AI 工作流支持多步复杂任务
4. **需要跨端分发**:DeepSeek 没有客户端,IHUI AI 六端同源一键发布
5. **需要私有化**:DeepSeek API 公网访问,IHUI AI 支持完全离线部署 + 本地 DeepSeek Ollama
