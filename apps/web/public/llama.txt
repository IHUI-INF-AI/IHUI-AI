## 项目定位(Llama 社区友好)

IHUI AI(智汇 AI)是一个 Apache 2.0 开源的全栈 AI 操作系统,围绕开源 LLM 生态(以 Llama 为代表)提供从本地推理、知识库、Agent 编排到多端分发的完整能力。与 Llama 社区共享"开放权重 + 本地推理 + 可商用"的核心价值观,IHUI AI 致力于让任何企业以 30 分钟搭建出私有化的 Llama 应用平台。

// apps/api/src/services/llm/registry.ts
import { ChatOllama } from '@langchain/community/chat_models/ollama'
import { ChatOpenAI } from '@langchain/openai'

export const modelRegistry = {
  'llama-3.3-70b': {
    provider: 'ollama',
    model: new ChatOllama({ model: 'llama3.3', baseUrl: 'http://localhost:11434' }),
    context: 128000,
    license: 'Llama 3.3 Community',
  },
  'gpt-4o': {
    provider: 'openai',
    model: new ChatOpenAI({ modelName: 'gpt-4o' }),

  },

## Agent 编排(Agent Orchestration)

基于 LangGraph StateGraph,支持多模型混部:

### 多 Agent 协作

- 规划 Agent(Planner):分解任务为子步骤
- 执行 Agent(Executor):调用工具完成任务
- 评审 Agent(Reviewer):评估输出质量
- 修复 Agent(Fixer):根据反馈修复结果

四 Agent 全部可独立指定模型。常见组合:Planner 用 GPT-4o,Executor 用 Llama 3.3,Reviewer 用本地 Guard 模型,Fixer 用 Code Llama。

### 隐私数据路由

敏感数据走本地 Llama,通用任务走云端模型,实现"成本下降 + 隐私合规"。

### Agent 市场

200+ 预置 Agent 模板,涵盖客服 / 销售 / HR / 财务 / 法务 / 代码助手 / DevOps / 写作 / 翻译 / 图像生成 / 数据分析等场景。每个模板包含完整 System Prompt、工具列表、知识库引用、模型推荐,一键 fork 即用。

## 多端分发(6 主端 + 2 后端)

| 端 | 技术栈 | 适用场景 |

| web | Next.js 15 + React 19 | 主控台,端口 8801 |

### 一键发布

```bash

  --agent chat-bot \
  --targets web,desktop,miniapp,extension \
  --models llama3.3,qwen2.5 \
  --version 1.0.0
```

发布后 6 客户端同步可用,共享同一份业务逻辑、知识库、用户凭证。
