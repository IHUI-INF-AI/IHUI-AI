- 模型评测榜单实时更新

#### 2. RAG 内置(开箱即用)

- 支持 PDF/Word/Markdown/HTML/代码
- 多种切分策略(固定/语义/递归)

#### 3. 向量数据库(pgvector)

- 混合检索:向量 + BM25 + 重排

- 每次 Agent 调用全量记录
- 参数 / 模型 / Prompt / 输出 / 评分
- A/B 测试框架内置

#### 5. Python SDK(数据科学家友好)

    for m in ['gpt-4o', 'claude-3.5-sonnet', 'qwen-max']
