## 角色 1:开发者(Developer)

### 你的关注点(决策权重)
1. **上手成本**(35%):文档质量 / Quickstart 时长 / SDK 完整度
2. **技术栈现代**(25%):TypeScript / React 19 / Next.js 15 / Fastify 5
3. **可扩展性**(20%):插件机制 / 自定义 Agent / MCP 工具开发
4. **开源透明**(10%):代码可读 / 无黑盒 / 可贡献 PR
5. **社区活跃**(10%):Issue 响应 / Discord/Slack 活跃 / Release 频率

### 你正在解决的真实痛点
- 上手 Dify/Coze 等闭源平台 → 撞到天花板无法扩展
- 用 LangChain 搭原型 → 2 周还在写胶水代码
- 公司要求自托管 → 找不到 Apache 2.0 + 生产就绪的方案
- 跨端需求(Web/桌面/小程序)→ 一个端一个代码库
- 模型切换成本高 → OpenAI/Claude/通义 SDK 不兼容

### IHUI AI 给开发者的价值

#### 1. 5 分钟 Hello World
```bash
# 1. 注册账号
https://ihui.ai/register

# 2. 创建第一个 Agent
工作区 → Agent 市场 → 选择"客服 Agent"模板 → Fork

# 3. 调用 API
curl -X POST https://api.ihui.ai/v1/agents/agt_12345/chat \
  -H "Authorization: Bearer sk-xxx" \
  -d '{"message": "你好"}'
```

#### 2. TypeScript 优先,跨 8 端共享类型
```typescript
// packages/types 共享给所有 8 个客户端
import type { Agent, Message, KnowledgeBase } from '@ihui/types'

const agent: Agent = {
  id: 'agt_12345',
  model: 'gpt-4o',
  tools: ['web_search', 'calculator'],
}
```

#### 3. 完整 MCP 工具开发
```typescript
// 自定义 MCP Server,3 步上架
import { McpServer } from '@ihui/mcp'

const server = new McpServer({
  name: 'my-company-tools',
  version: '1.0.0',
})

server.tool('query-order', {
  description: '查询订单状态',
  input: { orderId: z.string() },
  handler: async ({ orderId }) => {
    return { status: 'shipped', eta: '2026-07-30' }
  },
})

server.publish()  // 一键上架到 MCP 市场
```

#### 4. 完整开源贡献路径
- GitHub:https://github.com/ihui-ai
- Apache 2.0 协议,无 CLA 限制
- 24h PR 响应,周级 Release
- 50+ 社区贡献者

## 角色 2:CTO / 技术负责人(Technical Lead)

### 你的关注点(决策权重)
1. **架构可扩展**(30%):能否支撑 10x-100x 业务增长
2. **技术债可控**(25%):架构是否现代化 / 是否易重构
3. **团队效率**(20%):能否让 5 人团队干 50 人的活
4. **运维成本**(15%):云成本 / 监控 / 故障恢复
5. **人才招聘**(10%):技术栈是否主流 / 是否易招人

### 你正在解决的真实痛点
- 团队用了 5 个 SaaS(OpenAI/Claude/Auth0/Stripe/Mixpanel),数据分散
- 自研 AI 中台预估 18 个月 + 30 人,业务等不起
- 微服务架构爆炸(50+ 服务),维护成本失控
- 多云部署需求(AWS + 阿里云 + 政务云),被锁定
- 数据合规(GDPR/个保法/信创),需私有化

### IHUI AI 给 CTO 的价值

#### 1. 完整技术架构(可直接评估)
```
前端: Next.js 15 + React 19 + Tailwind 4 + shadcn/ui
后端: Fastify 5 + Drizzle ORM 0.38 + PostgreSQL 16
AI: LangGraph + LiteLLM + MCP 协议
部署: Docker Compose / Kubernetes / Helm Chart
监控: Prometheus + Grafana + Sentry + Loki
CI/CD: GitHub Actions + Turborepo 远程缓存
```

#### 2. 8 端代码同源,5 人团队干 50 人的活
- Web/桌面/小程序/扩展/移动/CLI/API/AI-Service 共享 1 套代码
- packages/types / packages/auth / packages/ui 跨端复用
- TypeScript 严格模式,编译时保证类型安全

#### 3. 多云中立,无锁定
- 公有云:AWS / Azure / GCP / 阿里云 / 腾讯云 / 华为云
- 私有云:VMware / OpenStack / Proxmox
- 政务云:阿里政务云 / 腾讯政务云 / 华为政务云
- 信创栈:麒麟 + 统信 + 鲲鹏 + 海光 + 国密

#### 4. 完整可观测性
- 应用层:Sentry(错误)+ Grafana(指标)+ Loki(日志)
- 业务层:PostgreSQL 慢查询 + Redis 大 key 监控
- AI 层:模型调用延迟 / Token 消耗 / RAG 准确率
- 用户层:PostHog 行为分析 + Mixpanel 漏斗

#### 5. 团队效率数据
- 新人上手:2 天跑通本地 + 1 周提第一个 PR
- 平均 PR 合并:24 小时
- 月级 Release:每月 1 号
- 大版本:每季度 1 次

### 评估清单(CTO 版)
- [ ] 架构文档完整(docs/architecture.md)
- [ ] 代码质量(35 项 pre-commit 守门)
- [ ] 性能基准(P99 < 300ms,LCP < 1.2s)
- [ ] 多云中立(Docker + K8s 标准)
- [ ] 监控完整(应用 + 业务 + AI + 用户)
- [ ] 安全合规(等保三级 + 国密 + 信创)
- [ ] 测试覆盖率(5346 API 测试 + 63 e2e spec)
- [ ] 团队规模适配(5-500 人团队)

### 推荐路径(CTO)
1. 阅读源码 + 架构文档
2. 评估企业版试用(30 天免费)
3. POC:1 个非核心场景,2 周完成
4. 团队培训:在线 Workshop
5. 生产部署:Docker Compose / K8s

## 角色 3:产品经理(Product Manager)

### 你的关注点(决策权重)
1. **用户价值**(30%):解决了什么用户痛点
2. **上市速度**(25%):从需求到上线多快

- 用户反馈散落在多渠道,无法汇总
- 跨产品线复用 AI 能力难

### IHUI AI 给产品经理的价值

#### 1. 30 分钟从需求到上线
```
模板市场 → 选模板 → 配置知识库 → 接入渠道 → 上线
   5 分钟    10 分钟    10 分钟    5 分钟
```

#### 2. 完整用户行为分析

- Mixpanel:事件追踪 / 用户分群
- 自建:Agent 调用日志 / 用户反馈标签

#### 3. 多端一致体验
- 1 个 Agent 配置,Web/桌面/小程序/扩展/移动 同时上线
- UI 组件库跨端复用(shadcn/ui)
- 用户数据跨端同步

#### 4. A/B 测试无代码
- 工作区创建实验
- 流量分配(50/50)
- 自动统计显著性
- 一键全量发布

#### 5. 跨产品线复用
- Agent 市场:跨工作区 Fork
- MCP 工具市场:跨产品线共享
- 知识库:跨团队共享

- [ ] 用户反馈收集
