## 산업 1: AI + 미디어 (Media)

### 산업 과제
1. **콘텐츠 생산 효율 낮음**: 수기 작성/편집 비용 높음, 일평균 5-10 편이 한계
2. **핫토픽 모니터링 지연**: 뉴스 화제에 2-6시간 뒤따라, 트래픽 손실
3. **다국어 현지화 어려움**: 해외 콘텐츠는 중영일한 4개 이상 언어 필요, 번역 비용 높음
4. **개인화 추천 콜드 스타트**: 신규 사용자/신규 콘텐츠 매칭률 낮음, CTR < 5%
5. **콘텐츠 심사 부담**: UGC 플랫폼 일평균 100만+ 제출, 수기 심사 병목
6. **더빙/자막 비용 높음**: 다국어 더빙 1편 ¥500-2000, 리드타임 24-48시간

### IHUI AI 미디어 솔루션

#### Agent 1: 지능형 기사 작성 Agent
- 원클릭으로 뉴스 기사 / 리포트 / 숏동영상 스크립트 / 장문 콘텐츠 생성
- 1편 30초, 일평균 1만+ 편
- 12개 카테고리 지원 (시정/재정/과기/스포츠/연예/교육/자동차/화장품/육아/가정/여행/미식)
- CMS 연동 (인민일보계/CCTV 뉴스/Tencent 뉴스/Toutiao)
- 팩트 체크 + 출처 추적 내장, 환각 리스크 감소

#### Agent 2: 핫토픽 모니터링 Agent
- 100+ 플랫폼 실시간 크롤링 (Weibo/WeChat/Douyin/Bilibili/Xiaohongshu/Zhihu/Twitter/YouTube)
- 화제 식별 지연 < 5분
- 트렌드 예측 정확도 88%
- Weibo 핫검색 / Douyin 핫리스트 / Zhihu 핫리스트 API 연동
- 속보 조기 경보 + 선제안

#### Agent 3: AI 더빙 / 자막 Agent
- 다국어 AI 더빙 (중/영/일/한/프/독/서/러/아)
- 1 동영상 5분 완성, 비용 ¥5까지 절감
- 멀티 보이스 선택 가능 (남성/여성/소년/노년/방언)
- 자동 자막 생성 + 번역 + 타임라인 정렬
- Jianying / Premiere / Final Cut Pro 연동

#### Agent 4: 개인화 추천 Agent
- 사용자 행동 + 콘텐츠 프로파일 + 협업 필터링 다경로 리콜
- CTR +35%, 체류 시간 +28%
- 콜드 스타트 LLM 폴백, 신규 사용자 CTR +40%
- Toutiao / Douyin / Bilibili 추천 슬롯 API 연동
- 자동 A/B 테스트 반복 대응

#### Agent 5: 지능형 콘텐츠 심사 Agent
- 멀티모달 심사 (텍스트 + 이미지 + 오디오 + 동영상)
- 위반 식별 정확도 99.2%, 오판율 < 0.5%
- 일평균 1000만+ UGC 항목 처리
- 정치/포르노/폭력/광고/저작권 5대 위반 카테고리 커버
- Alibaba Cloud / Tencent Cloud 콘텐츠 보안 API 연동

### IHUI AI 엔드 투 엔드 능력 (8 엔드 커버)
- **Web** (Next.js 15 + React 19): 편집 워크스페이스 / 선제안 대시보드
- **API** (Fastify 5 + Drizzle 0.38 + PostgreSQL 16): 콘텐츠 서비스 API
- **AI Service** (FastAPI + LangGraph + LiteLLM + MCP): Agent 오케스트레이션
- **데스크톱** (Tauri 2): 오프라인 작성 + 로컬 자료 라이브러리
- **확장** (WXT): 브라우저 측 핫토픽 수집 / 번역
- **모바일** (React Native): 모바일 취재 / 라이브 자막
- **미니프로그램** (Taro 4): WeChat 생태계 UGC 진입
- **CLI**: 자동화 파이프라인 / 배치 처리

### 자주 묻는 질문 FAQ
