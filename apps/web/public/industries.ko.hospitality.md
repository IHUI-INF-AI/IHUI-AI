## 산업 5: AI + 호텔·음식 (Hospitality)

### 산업 과제
1. **고객지원 상담량 큼**: 예약/취소/음식 예약 일평균 백만급 상담
2. **고객 기호 통찰 얕음**: 기초 정보만, 개인화 추천 어려움
3. **마케팅 카피 작성 지연**: 다채널 (WeChat/Douyin/Xiaohongshu) 콘텐츠 부족
4. **메뉴 기술 단조**: 시각적 매력 낮음, 전환율 낮음
5. **리뷰 분석 시간 소요**: 백만 건 리뷰 수기 분석은 비현실적
6. **입지/가격 책정 경험 의존**: 신규 매장 개업 실패율 30-50%

### IHUI AI 호텔·음식 솔루션

#### Agent 1: 지능형 고객지원 Agent (예약/취소)
- 7×24 지능형 Q&A (예약/취소/변경/인보이스/멤버십)
- 90% 상담을 AI가 직접 해결
- 다채널 (WeChat 미니프로그램 / 공식 계정 / APP / 전화)
- PMS 연동 (Opera / 셰청 / 메이톈)
- 12개 언어 국제화 서비스 지원

#### Agent 2: 고객 기호 분석 Agent
- 투숙 이력 + 음식 소비 + 리뷰 + 행동 다차원 프로파일
- 재방문율 +25%
- 개인화 객실 / 음식 추천
- CRM 연동 (Shiji / Wanneng / 자체)
- 프라이버시 컴플라이언스: 데이터 익명화 + 사용자 수락

#### Agent 3: 마케팅 카피 Agent
- 원클릭으로 다채널 카피 생성 (WeChat / Douyin / Xiaohongshu / Weibo / OTA)
- 숏동영상 스크립트 + 카피 + 포스터 카피
- 단일 매장 월 평균 1000+ 편 생산
- 기업 WeChat / Douyin 기업 호 / Xiaohongshu 기업 호 연동
- 명절 / 핫토픽 신속 대응

#### Agent 4: 지능형 메뉴 Agent
- 원클릭으로 이미지 + 동영상 메뉴 생성
- 다국어 (중/영/일/한/불/서)
- 식재료 추적 + 영양 라벨 자동 생성
- 메이톈 / 대중점평 / 미니프로그램 주문 연동
- 전환율 +30%

#### Agent 5: 리뷰 분석 Agent
- 백만급 리뷰 자동 귀속 (악평 원인 / 호평 키워드 / 개선 제안)
- 감성 분석 정확도 92%
- 경쟁사 벤치마킹 + 트렌드 예측
- 대중점평 / 셰청 / 비저 / TripAdvisor 연동
- 매장 개선 제안 자동 배정

### 컴플라이언스 요건 (호텔·음식 산업)
- ✅ 《여행 호텔 성급 구분과 평정》(GB/T 14308)
- ✅ 《식품 안전법》
- ✅ 《소비자 권익 보호법》
- ✅ 《개인정보보호법 (PIPL)》

- ✅ 등보 2급 (대형 그룹은 3급 요구)
- ✅ 식품 경영 허가증 / 음식 서비스 허가증
- ✅ 위생 감독 + 식품 검체 보관
- ✅ 감사로그 3년 보관

### IHUI AI 엔드 투 엔드 능력 (8 엔드 커버)
- **Web** (Next.js 15 + React 19): 본부 운영 / 매장 대시보드
- **API** (Fastify 5 + Drizzle 0.38 + PostgreSQL 16): 주문/멤버 API
- **AI Service** (FastAPI + LangGraph + LiteLLM + MCP): 다중 Agent 협조
- **데스크톱** (Tauri 2): 매장 관리 워크스테이션
- **확장** (WXT): 브라우저 측 리뷰 수집
- **모바일** (React Native): 매장 점장 앱
- **미니프로그램** (Taro 4): 예약 / 주문 / 멤버십
- **CLI**: 배치 메뉴 생성 / 리뷰 분석
