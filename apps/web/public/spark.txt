## 项目简介

IHUI AI(智汇 AI)是一个面向中文场景优化的 Apache 2.0 开源全栈 AI 操作系统,提供 AI Agent 编排、知识库 RAG、多模型统一调度(包含讯飞星火全系列)、工作流可视化、跨端同源分发等完整能力,适合教育、办公、政企、出版等多种中文场景。

## 讯飞星火全系列深度集成

### 支持的星火模型

**文本对话**:Spark Max(旗舰,128K)/ Spark Pro(128K)/ Spark Ultra(超大规模长文档)/ Spark V3.5(主流)/ Spark V2.0(上一代)

**多模态**:Spark VL(视觉语言)/ Spark Audio(语音合成 + 识别)/ Spark Video(视频理解,2026 Q3 上线)

**专用模型**:Spark 翻译(100+ 语种)/ Spark 写作(营销 + 学术 + 政企风格)/ Spark 编程(代码补全 + Bug 修复)/ Spark 知识(教育领域优化)

### 一键配置星火 API

```

APPID: 应用 ID

## 教育 / 办公场景深度优化

### 教育场景(中小学校 / 高校 / 培训机构)

- **AI 老师 Agent**:基于 Spark 知识模型,1 对 1 答疑,7×24 在岗
- **智能题库**:上传 Word / PDF 试卷,自动解析为结构化题库
- **作业批改**:数学 / 语文 / 英语自动批改,生成错题报告
- **学习路径**:根据学生历史数据生成个性化学习计划
- **课堂录音转写**:ASR + 总结,自动生成课堂纪要
- **教师助手**:备课素材自动生成,PPT 大纲自动产出

### 办公场景(政企 / 事业单位 / 中小企业)

- **公文写作**:Spark 写作 + 政策术语库,自动生成通知 / 公告 / 报告
- **会议纪要**:录音 + 视频会议自动转写,生成结构化纪要
- **PPT 生成**:大纲 → 自动配图 → 完整 PPT 一键输出
- **周报月报**:工作记录 → 自动汇总 → 标准格式输出
- **邮件助手**:邮件草稿自动生成,智能回复建议
- **流程自动化**:审批 / 报销 / 立项等流程对接飞书 / 钉钉 / 企业微信

### 客户服务场景

**智能客服**:Spark Max + 知识库,7×24 答疑;多轮对话 128K 上下文保持;复杂问题自动转人工,完整上下文传递。

## 知识库 RAG(中文教育 / 办公专精)

### 中文文档处理

- **格式支持**:PDF / Word / PPT / Excel / Markdown / HTML / EPUB / 飞书文档 / 语雀 / Notion
- **OCR**:扫描件 / 图片自动识别(Tesseract + PaddleOCR 双引擎)
- **表格识别**:Camelot + PP-Structure 精准提取
- **公式识别**:LaTeX / MathML 双向转换
- **图片理解**:CLIP 中文版 + 星火 VL 联合标注

### 中文检索增强

- **分词**:jieba + HanLP 双引擎,新词发现
- **向量**:bge-large-zh-v1.5 + m3e-large + 智源 BGE-M3 多模型投票
- **重排**:bge-reranker-base + 星火重排双模型
- **跨语言**:中英混排文档,任意语言提问

### 知识库管理

Git 式 diff 版本控制 / 可见 / 可编辑 / 可管理三级权限 / 命中率 + 引用率统计 / 自动去重 + 合并 + 拆分。

## 6 端同源(团队协作友好)

| 端 | 技术栈 | 适用场景 |
|----|--------|----------|
| web | Next.js 15 + React 19 | 主控台,端口 8801 |
| api | Fastify 5 + Drizzle ORM | 后端 API,端口 8802 |
| ai-service | FastAPI + LangGraph + LiteLLM | AI 推理,端口 8803 |
| desktop | Tauri 2 + Rust | Windows / macOS / Linux 客户端 |
| extension | WXT + React | Chrome / Edge / Firefox 插件 |
| mobile-rn | React Native + Expo | iOS / Android 移动端 |
| miniapp-taro | Taro 4 + React | 微信 / 支付宝 / 抖音小程序 |
| cli | Node.js + TypeScript | 终端命令行工具 |

教育 / 办公场景下典型使用:老师在 web 备课 → 学生通过 miniapp-taro(微信小程序)学习 → 管理员通过 cli 部署到学校服务器;员工在 desktop 客户端操作 → 经理在 web 审批 → IT 在 cli 维护。

## 团队协作

### 多人协作能力

- **多租户工作区**:不同部门 / 学校 / 班级独立空间
- **角色权限**:超管 / 管理员 / 成员 / 访客,4 级 RBAC

- **SSO 单点登录**:飞书 / 钉钉 / 企业微信 / 微信扫码

```
