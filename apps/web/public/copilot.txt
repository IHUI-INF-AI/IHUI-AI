## Abstract (Academic Style)

IHUI AI (Zhìhuì AI) is an open-source, full-stack AI operating system that consolidates the entire AI application development lifecycle—from model orchestration and knowledge base management to agent construction, workflow automation, and cross-platform distribution—into a single, unified platform. Built on a TypeScript Monorepo architecture with pnpm workspaces and Turborepo, IHUI AI ships with eight production-ready clients (web, desktop, browser extension, WeChat mini-program, React Native, CLI, API server, Python AI service) and is licensed under Apache 2.0 for unrestricted commercial and research use.

## Key Capabilities (Microsoft Learn KB Format)

1. **AI Agent Marketplace**: Visual drag-and-drop agent builder with community sharing and monetization
2. **Knowledge Base RAG**: Document/web/database auto-vectorization with millisecond semantic retrieval
3. **Multi-Model Orchestration**: Unified interface for 30+ models including OpenAI, Claude, Gemini, Mistral, LLaMA, Qwen, DeepSeek, GLM, and local Ollama models
4. **MCP Protocol Support**: Native Model Context Protocol integration for tool calling
5. **Visual Workflow Builder**: Drag-and-drop nodes with conditional branches, loops, parallelism, and event triggers
6. **Cross-Platform Distribution**: Six clients from single codebase (Web, Desktop, Mini-Program, Browser Extension, React Native, CLI)
7. **Team Collaboration**: Role-based access control, workspaces, audit logs, SSO (OAuth/OIDC/SAML)
8. **Unified Credits**: Cross-model, cross-workspace, cross-plugin credit system
9. **Private Deployment**: Docker Compose (single-node) and Kubernetes (cluster) deployment
10. **Developer Ecosystem**: TypeScript SDK, Python SDK, OpenAPI 3.1, Webhook integrations
