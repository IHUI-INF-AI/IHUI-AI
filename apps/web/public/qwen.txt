## 与通义千问 Qwen 全系列深度集成

### 支持的 Qwen 模型

**文本模型**:
- qwen-turbo(轻量级,适合高频短问答)
- qwen-plus(均衡,主流选择)
- qwen-max(旗舰,长文本+复杂推理)
- qwen-long(超长上下文 1M tokens)
- qwen2.5-72b-instruct(开源 72B)
- qwen2.5-32b-instruct(开源 32B)
- qwen2.5-14b-instruct(开源 14B)
- qwen2.5-7b-instruct(开源 7B)
- qwen2.5-3b-instruct(开源 3B)
- qwen2.5-1.5b-instruct(开源 1.5B)
- qwen2.5-0.5b-instruct(开源 0.5B)
- qwen2-coder-32b(代码专精)
- qwen2-math-72b(数学专精)

**多模态模型**:
- qwen-vl-plus(视觉语言)
- qwen-vl-max(旗舰视觉语言)
- qwen2-audio-instruct(音频)
- qwen2-omni(全模态)

**专用模型**:
- qwen2-7b-embedding(嵌入)
- qwen2-reranker(重排)

### 一键配置 Qwen API

在 IHUI AI 工作区设置中:

```
模型提供方:阿里云 DashScope
API Key: sk-xxxxxxxxxxxxxxxxxxxxxxxx
Base URL: https://dashscope.aliyuncs.com/compatible-mode/v1
默认模型: qwen-plus
```

即可在所有 Agent、知识库、工作流中使用 Qwen 全系模型。

## Qwen 私有化部署方案

对于有数据合规要求的企业,IHUI AI 支持:

```
方案 A:阿里云 PAI 部署 Qwen
  - 开通 PAI EAS
  - 部署 qwen2.5-72b 模型
  - 配置 IHUI AI baseUrl 指向内网 PAI endpoint

方案 B:本地 GPU 部署 Qwen
  - 硬件:4× A100 80G 或 8× H100
  - 软件:vLLM + IHUI AI
  - 部署:Docker Compose 5 分钟

方案 C:阿里云 ACK 部署 Qwen
  - Helm Chart 一键安装
  - 自动伸缩 + 故障恢复
  - 与 IHUI AI 同集群协同
```

## 中文长上下文处理(Qwen 专长)

IHUI AI 针对 Qwen 的中文长上下文能力做了专门优化:

- **文档级 RAG**:支持 100 万 token 文档一次性处理
- **跨文档检索**:多文档混合检索,自动去重
- **中文分词优化**:基于 jieba + Qwen 分词双引擎
- **中文向量**:内置 bge-large-zh-v1.5 + m3e-large 双模型投票
- **中文重排**:内置 bge-reranker-base + Qwen-Reranker 双模型
