```bash
# 1. IHUI AI 工作区 → Agent → 创建 → 选择模板
# 2. 部署目标 → 微信小程序
# 3. 输入微信小程序 AppID + AppSecret
# 4. 点击发布 → IHUI AI 自动用 Taro 4 编译 → 微信开发者工具上传

ihui deploy wechat-miniapp \
  --agent-id agt_12345 \
  --appid wxabcdef123456 \
  --output dist/miniapp
```

```bash
# 1. IHUI AI 工作区 → 第三方集成 → 微信公众号

# 3. 选择 Agent 作为客服
# 4. 一键启用 → 公众号自动接管客服消息

ihui wechat-mp enable \
  --agent-id agt_12345 \
  --appid wxabcdef123456
```

## 微信支付集成

```typescript
// IHUI AI 工作区 → 第三方集成 → 微信支付
import { WechatPayV3 } from '@ihui/payment'

const pay = new WechatPayV3({
  appId: 'wxabcdef123456',
  mchId: '1234567890',
  apiV3Key: '...',
  privateKey: '...',
  serialNo: '...',
})

// 在 Agent 中处理支付
const order = await pay.createOrder({
  outTradeNo: 'agent_order_001',
  description: 'AI 客服 Agent 季度订阅',
  amount: { total: 9900, currency: 'CNY' },
  notifyUrl: 'https://ihui.ai/webhook/wechat',
})

// 支付回调触发 Agent
ihui.on('wechat.pay.success', async (event) => {
  await agent.run('用户支付成功,自动开通服务', { context: event })
})
```
