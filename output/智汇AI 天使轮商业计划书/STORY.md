# STORY.md — 智汇AI 天使轮路演 BP

## ① 用户意图对齐

- **目标受众**：一级市场投资人（VC / 天使 / 产业资本），微信转发与现场路演两用。
- **核心目标**：让投资人相信"这个产品已经建成、不是概念"，并记住"整合入口 + 开源飞轮"两个关键词，最终约见创始人深聊 2000 万天使轮。
- **PPT 长度**：15 页（Hero 页配额 3-4 页，取 3 页）。
- **视觉调性**：权威 / 数据冲击 / 克制 / 商务咨询风 / 大字少文。
- **内容边界**：必讲——产品已建成的硬核证据、市场空间、商业模式、团队、融资方案；不讲——公众号运营细节、内部工程流程；禁碰——夸大且无法验证的收入数字、多级分销表述（合规）。

## ② 页面布局骨架

15 页 3 章：目录声明 3 个章节，全篇有且仅有 3 个 section 扉页，一一对应。

- 目录第 1 章「机会」→ 第 3 页 section 扉页（01），覆盖 p4-p5
- 目录第 2 章「产品」→ 第 6 页 section 扉页（02），覆盖 p7-p9
- 目录第 3 章「商业」→ 第 10 页 section 扉页（03），覆盖 p11-p14

Hero 页：p1（封面）、p8（硬核数据大数字）、p15（结束页）= 3/15 = 20%，Hero 之间均有 ≥1 个 Supporting 页间隔。

rhythm 曲线：p1 peak → p2 valley → p3 transition → p4 valley → p5 peak → p6 transition → p7 valley → p8 peak → p9 valley → p10 transition → p11 valley → p12 peak → p13 valley → p14 peak → p15 peak。无连续 ≥3 页 valley。

非对称版式（7 页 ≥ 40%）：p1 全幅骑线、p4 非对称双栏、p5 巨型数字+洞察、p8 大数字群、p9 非对称双栏、p14 巨型数字+时间轴、p15 全幅骑线。对称版式仅 p2 目录、p7/p11 结构图、p12 图表+洞察、p13 对比表。

- 1.8—2.2 万亿美元 → 含义：应用层整合平台是本轮周期确定性最高的入口型机会
- 109 万行代码 / 14800+ 测试 → 含义：竞品补齐同等能力需百万行级研发投入，构成复制成本壁垒

- 2000 万 / 15% → 业务影响：投前估值约 1.13 亿，到下轮预计 10 倍估值增长
