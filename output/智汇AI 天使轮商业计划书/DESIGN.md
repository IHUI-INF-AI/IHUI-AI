# DESIGN.md — 智汇AI 天使轮路演 BP

> v2 定稿：**AI 发布会风（暗色科技风）**。v1 商务咨询风（白底 Navy）因"不够吸睛、不专业"被用户否决，2026-09-07 全篇 15 页重做。

## 画布与骨架

- 画布 1280×720；内页 padding 52px 56px。
- 内页结构：页眉角标（右上 14px 灰 #64748B 章节名）→ Action Title 33px 白 Bold → 1px 分隔线 rgba(255,255,255,0.14) → 内容区 → 页脚（左 Source 14px 灰 / 右页码 NN / 15）。
- 封面/扉页/结尾页无页眉页脚；扉页无页码。

## 色彩系统（暗色）

| 角色 | 值 | 用途 |
|------|-----|------|
| 底色 | linear-gradient(165deg, #0B1322 → #070B14 → #0A0F1E) | 全部页面背景（深空纵深底光） |
| 主渐变 | linear-gradient(135deg, #22D3EE → #818CF8) | 大数字渐变文字、强调条、时间轴当前节点、资金条 |
| 青 #22D3EE / 靛 #818CF8 | 强调色 | 高亮文字、边框、图表线 |
| 正文字 | #E2E8F0 / #CBD5E1 | 标题白 #FFFFFF，正文浅灰 |
| 次要字 | #94A3B8 / #64748B | 说明、页脚 |
| 玻璃卡 v3（悬浮） | background rgba(255,255,255,0.07-0.08) + border 1px rgba(255,255,255,0.12-0.18) + borderRadius 14-20 + boxShadow 0 10-14px 28-40px rgba(0,0,0,0.4-0.5) | 所有卡片，悬浮感 |
| 渐变玻璃卡 | linear-gradient(135deg, rgba(34,211,238,0.14~0.25), rgba(129,140,248,0.14~0.25)) + border rgba(34,211,238,0.35~0.5) | 焦点卡/表头/结论条 |
| 氛围光斑 | absolute radial-gradient rgba(34,211,238,0.14~0.28) / rgba(129,140,248,0.18~0.25)，负偏移出血 | 每页 1-2 个，忌遮挡文字 |

## 字体与字号（1 套家族）

`Arial, "Microsoft YaHei", "PingFang SC", sans-serif`（Arial 管数字/英文，雅黑管中文；所有元素显式声明，禁止依赖渲染器默认字体）

| 层级 | px |
|------|-----|
| 扉页巨字编号（渐变文字） | 260 |
| 封面主标（白→青渐变文字） | 92 |
| KPI 大数（渐变文字） | 88–110；数据页 44 |
| Action Title | 33 |
| 卡片标题 | 21–25 |
| 正文 | 19–22 |
| Source/页码 | 14 |

大数字用渐变文字：color:'transparent' + backgroundImage + backgroundClip:'text'；单位用独立 span 白色/浅灰。

## 版式纪律

- 每页 1 个视觉重心（渐变大数字 / 渐变卡 / 图表）；正文短句化，≤22 字/句。
- 相邻页版式不重复；卡片等宽等高；内容撑满 C 区。
- 已上线 = 青色边卡；已建成 = 灰色边卡（p7 图例语言）。
- 章节扉页：左侧 260px 渐变巨字编号（01/02/03），右侧 52px 白标题 + 渐变短条 + 英文小标 + 一句摘要。
