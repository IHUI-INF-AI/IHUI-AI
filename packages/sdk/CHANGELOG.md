## [Unreleased]

## [0.1.0]

首个对外发布候选版本(尚未发布到 npm)。

### Added

- TypeScript 客户端,覆盖 13 个模块、105 个 `/v1/*` 端点:对话 / Agent / 音频 / 图像 /
  视频 / 3D / 生成队列 / 知识库 / 工具 / 记忆 / 消息 / 文件 / 用户。
- 零运行时依赖;内置流式解析(`parseChatStream` / `parseAgentStream`)与 Agent Engine
  编排层(`createAgent`)。
- `SdkError.retryAfterMs`:错误响应携带 `Retry-After` 头(整数秒或 HTTP 日期)时解析为
  建议等待毫秒数,供调用方对 429 自适应退避(429 仍不自动重试)。
- `exports` 映射与 `files` 白名单只发布 `dist/` 编译产物;声明文件自包含
  (`@ihui/types` 的 V1 契约在构建期内联进 `dist/ihui-types.d.ts`)。
- Apache-2.0:发布物随包附带 `LICENSE` 与 `NOTICE`;本 `CHANGELOG.md` 亦随包附带。
- README 对外承诺四段:鉴权获取指引、限流与 429(含自适应退避接入示例)、版本与稳定性
  (SemVer / 0.x 语义 / 兼容面 / 弃用策略)、遥测与隐私(零遥测 / 网络边界)。
